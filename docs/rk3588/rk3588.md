# RK3588 开发心得

## 1. HDMI CEC

```bash
# 关闭电视（待机）
cec-ctl --standby --to 0

# 打开电视
cec-ctl --image-view-on --to 0

# 查看 One-touch-play 帮助
cec-ctl --help-one-touch-play
```

> 并非所有 HDMI 设备都支持 CEC，需确认 TV 端是否支持 CEC 及对应指令。

**调试节点**：`/sys/kernel/debug/cec/cec0/status`

## 2. 蓝牙（Bluetooth）

### bluetoothctl 提示 "No default controller available"

原因：系统自带的 bluetoothd 与自编译的 bluez 版本冲突。

```bash
# 1. 停止系统自带 bluetoothd
rfkill block bluetooth
sudo service bluetooth stop
rfkill unblock bluetooth

# 2. 启动自编译的 bluetoothd
./bluetoothd -n -d &

# 3. 再执行 bluetoothctl 即可检测到 hci 设备
./bluetoothctl
```

### 常用蓝牙命令

**hciconfig** — 管理蓝牙设备：

```bash
hciconfig -a            # 显示所有蓝牙设备详细信息
hciconfig hci0 up       # 启用 hci0
hciconfig hci0 down     # 禁用 hci0
hciconfig hci0 reset    # 重置 hci0
hciconfig hci0 piscan   # 启用可发现模式
hciconfig hci0 noscan   # 禁用可发现模式
```

**hcitool** — 扫描和连接：

```bash
hcitool scan            # 扫描周围可见蓝牙设备
hcitool dev             # 显示已连接的蓝牙设备
hcitool con             # 显示已建立连接的设备
hcitool lq <addr>       # 显示信号质量
hcitool cc <addr>       # 建立连接
hcitool dc <addr>       # 断开连接
```

> 参考：[RTL8821CS 移植过程记录](https://blog.csdn.net/weixin_43982460/article/details/116009321)

## 3. GPIO

RK3588 有 5 个 GPIO 控制器（GPIO0-GPIO4），每个控制器管理 32 个 IO，端口固定为 A、B、C、D。

### GPIO 编号换算

```
GPIOa_bc → pin = a × 32 + (b序号 - 1) × 8 + c

其中 b: A=1, B=2, C=3, D=4
```

常用示例：

| GPIO | 计算 | Pin |
| ---- | ---- | --- |
| GPIO0_C2 | 0×32 + 2×8 + 2 | 18 |
| GPIO0_C6 | 0×32 + 2×8 + 6 | 22 |
| GPIO1_A4 | 1×32 + 0×8 + 4 | 36 |
| GPIO1_B0 | 1×32 + 1×8 + 0 | 40 |
| GPIO1_C0 | 1×32 + 2×8 + 0 | 48 |
| GPIO1_C1 | 1×32 + 2×8 + 1 | 49 |
| GPIO1_C4 | 1×32 + 2×8 + 4 | 52 |

### GPIO sysfs 操作

```bash
# 申请 GPIO
echo 36 > /sys/class/gpio/export

# 设置为输出
echo out > /sys/class/gpio/gpio36/direction

# 输出高电平
echo 1 > /sys/class/gpio/gpio36/value

# 读取当前值
cat /sys/class/gpio/gpio36/value

# 释放 GPIO
echo 36 > /sys/class/gpio/unexport
```

## 4. IR 红外遥控

- **DTS**：`vhd-t730p-rk3588.dts`
- **驱动**：`drivers/input/remotectl/rockchip_pwm_remotectl.c`
- **IR 引脚**：PWM3_IR，芯片引脚 C25

> 驱动一般不需要修改，只需在 DTS 中建立新的键值匹配表。

### 调试步骤

```bash
# 1. 开启键值调试打印
echo 1 > /sys/module/rockchip_pwm_remotectl/parameters/code_print

# 2. 按遥控器按键，记录 usercode 和键值
#    例如按向下键，打印：
#    GET USERCODE=0x4040
#    RMC_GETDATA=e9
#    → usercode = 0x4040，向下键值 = 0xe9

# 3. 查看对应的 event 设备
cat /proc/bus/input/devices

# 4. 实时调试 event
getevent -l /dev/input/event0
```

### DTS 配置示例

```dts
&pwm3 {
    status = "okay";
    compatible = "rockchip,remotectl-pwm";
    pinctrl-names = "default";
    pinctrl-0 = <&pwm3m3_pins>;
    remote_pwm_id = <3>;
    handle_cpu_id = <1>;
    remote_support_psci = <1>;

    ir_key1 {
        rockchip,usercode = <0xb748>;
        rockchip,key_table =
            <0xf6  KEY_REPLY>,    // home
            <0xfa  KEY_UP>,
            <0xf2  KEY_DOWN>,
            <0xf7  KEY_LEFT>,
            <0xf5  KEY_RIGHT>,
            <0xda  KEY_BACK>,
            <0xf0  KEY_MENU>,
            <0xf3  KEY_1>,
            <0xee  KEY_2>,
            <0xf1  KEY_3>,
            <0xfb  186>,          // zoom -
            <0xff  185>,          // zoom +
            <0xf8  KEY_VOLUMEUP>,
            <0xdb  KEY_VOLUMEDOWN>,
            <0xf4  KEY_MUTE>,
            <0xdc  KEY_POWER>;
    };
};
```

## 5. 云台配置

配置文件：`/vendor/etc/motor_params/m2000s.json`

| 参数 | 说明 |
| ---- | ---- |
| enable_gpio | 使能 GPIO 引脚 |
| step_gpio | 步进脉冲 GPIO |
| dir_gpio | 方向 GPIO |
| dete_gpio | 检测 GPIO |
| min/max_position | 行程范围 |
| init_position | 初始位置 |
| privacy_position | 隐私位 |
| min/max_angle | 角度范围 |
| max_speed | 最大速度 |
| speed[] | 各档位速度表 |
| acc[] | 各档位加速度表 |
| track_speed[] | 跟踪模式速度表 |
| track_acc[] | 跟踪模式加速度表 |

两个通道分别对应水平（CHANNL0）和垂直（CHANNL1）方向。详细配置见设备上的 JSON 文件。
