# MS41969开发

## 芯片概述

**MS41969** 是杭州瑞盟科技有限公司（Relmon）生产的一款**双通道超低噪声 256 细分微步进 12V 电机驱动器**，内置功率 MOSFET，支持两路步进电机驱动（α通道 AB、β通道 CD）和一路直流电机驱动（E通道）。

芯片通过电压驱动方式 + 电流细分 + 扭矩纹波修正技术实现超低噪声运行，内置晶振放大模块，可使用无源晶振。

典型应用：机器人、精密工业设备、摄像机、监控摄像机（焦距/倍率控制、IR-cut 切换）。

## 功能框图

```
MS41969 包含：
├── 步进电机驱动 A/B（α通道）  →  OUTA1/A2, OUTB1/B2
├── 步进电机驱动 C/D（β通道）  →  OUTC1/C2, OUTD1/D2
├── 直流电机驱动 E              →  OUTE1/E2
├── 四线串行总线接口            →  CS/SCK/SIN/SOUT
├── 晶振电路                   →  OSCIN/OSCOUT
├── 同步信号输入               →  VF1/VF2（视频同步）
└── 监控脉冲输出               →  PLS1/PLS2
```

## 控制接口

MS41969 使用四线串行总线（SPI）控制，通信时序：

- **数据格式**：24 位 / 次传输
- **时钟频率**：1 ~ 5 MHz
- **数据在 SCK 上升沿写入 IC**
- **SOUT 在 CS = 0 时为高阻态**

### 数据帧格式

| 位 | 内容 |
|----|------|
| D15~D10 | A5~A0：寄存器地址 |
| D9 | C1：未使用 |
| D8 | C0：0=写模式，1=读模式 |
| D7~D0 | D0~D7：数据（低字节） |
| D15~D8 | D8~D15：数据（高字节） |

## 步进电机控制

### 细分模式

MICROAB / MICROCD 设置正弦波细分数：

| 设置值 | 细分数 |
|--------|--------|
| 00 | 256 细分 |
| 01 | 256 细分 |
| 10 | 128 细分 |
| 11 | 64 细分 |

### 转速计算

**步骤 1**：计算 INTCTxx[15:0]

```
INTCTxx[15:0] = OSCIN频率 / (转动频率 × 768)
```

**步骤 2**：计算 PSUMxx[7:0]

```
INTCTxx × PSUMxx × 24 = OSCIN频率 / VFx频率
```

**步骤 3**：由 PSUMxx 反算 INTCTxx

### 计算示例

OSCIN = 27MHz，VFx = 60Hz，目标转速 800pps（1-2 相位）：

```
INTCT = 27MHz / (100Hz × 768) = 352
PSUM = 27MHz / (60Hz × 352 × 24) = 53
重新计算 INTCT = 27MHz / (60Hz × 53 × 24) = 354
```

### 相位矫正

PHMODAB / PHMODCD 用于矫正线圈 A/B（C/D）之间的相位差，默认 90°，调节范围 -22.5° ~ +21.8°，单位 0.7°/级。

### PWM 频率

PWMMODE × PWMRES 共同决定 PWM 频率：

```
PWM频率 = OSCIN频率 / ((PWMMODE × 8) × 2^PWMRES)
```

OSCIN = 27MHz 时，部分 PWM 频率对照：

| PWMMODE | PWMRES=0 (kHz) | PWMRES=1 (kHz) | PWMRES=2 (kHz) |
|---------|---------------|---------------|---------------|
| 1Ch | 198.5 | 99.3 | 49.6 |
| 1Eh | 153.4 | 76.7 | 38.4 |
| 20h | 140.6 | 70.3 | 35.2 |

## 直流电机驱动（E 通道）

直流电机通过 SPI 寄存器 2Ch 控制，用于 IR-cut 切换：

| IN1 | IN2 | OUTE1 | OUTE2 | 电机状态 |
|-----|-----|-------|-------|----------|
| 0 | 0 | Z | Z | 刹车 |
| 0 | 1 | L | H | 反转 |
| 1 | 0 | H | L | 正转 |
| 1 | 1 | L | L | 高阻态 |

## 同步信号（VFx）

VF1 / VF2 是视频同步信号输入，用于：

1. 触发步进电机转动
2. 与步进电机步进计数同步
3. 极性可通过 MODESEL_FZ 寄存器取反

## 保护功能

| 保护类型 | 说明 |
|----------|------|
| 过温保护 (TSD) | 145°C 起效，滞后 35°C |
| 欠压锁定 (UVLO) | DVDD < 2.48V / MVCCx < 2.42V 时关断输出 |
| 复位 | RSTB 低电平复位所有寄存器 |

## 开发要点

### 典型接线

1. **电源**：AVDD (3.3V)、DVDD (5V)、VDD5 (5V)、MVCCx (12V)
2. **晶振**：OSCIN/OSCOUT 之间接无源晶振，或 OSCIN 接有源晶振输出
3. **步进电机**：OUTA1/A2 → 线圈 A，OUTB1/B2 → 线圈 B（同理 C/D）
4. **直流电机**：OUTE1/OUTE2 → IR-cut 电机
5. **同步信号**：VF1/VF2 → 视频同步信号源
6. **SPI 控制**：CS/SCK/SIN/SOUT → MCU

### 寄存器初始化顺序

1. 设置 RSTB = 高，释放复位
2. 配置 PWM 频率（PWMMODE / PWMRES）
3. 配置 DT1（起始点等待时间）
4. 配置 DT2A / DT2B（起始点激励等待时间）
5. 配置相位矫正（PHMODAB / PHMODCD）
6. 配置峰值脉冲宽度（PPWA~PPWD）
7. 配置转动方向（CCWCWAB / CCWCWCD）
8. 启动电机（设置 PSUM > 0，INTCT > 0）

### 散热设计

QFN36 封装带散热片（PAD），大功率应用时必须接地并良好散热。

## 与 MS35774 对比

| 对比项 | MS41969 | MS35774 |
|--------|---------|---------|
| **通道数** | 双通道步进 + 直流电机 | 单通道步进 |
| **驱动电流** | ±1.2A（步进）/ ±0.5A（直流） | ±2A |
| **控制接口** | SPI（寄存器配置） | STEP/DIR（无 SPI） |
| **细分** | 64/128/256 可选 | 固定 256 内部细分 + 外部 2/4/8/16 |
| **同步信号** | VFx（视频同步） | 无 |
| **内置运动控制器** | 无（需外部 MCU 控制） | 无 |
| **封装** | QFN36 | QFN-28 |
| **典型应用** | 摄像机焦距/倍率/IR-cut | 3D 打印机、云台 |
