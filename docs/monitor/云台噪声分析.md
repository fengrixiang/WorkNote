# QSC 云台系统深度降噪分析与优化指南
*(Based on TMC5272 Datasheet Rev 1, 4/24)*

> **核心结论前置**：
> 当前系统的高频及匀速段噪声，经多轮分析与排查，已彻底排除“力矩不足导致机械丢步”的可能。**核心真凶被锁定为：纯粹的电控参数配置不当引发的“电磁激振”**。在 12V 供电 + 8.2mH 高电感电机的前提下，当前的 TMC5272 SpreadCycle 斩波参数（特别是过小的 `TOFF`）导致电流严重畸变。畸变的锯齿波电流像高频锤子一样敲击转子，引发了巨大的空载/负载“嗡嗡”声。

### 物理瓶颈分析：严重的“电流饥饿 (Torque Starvation)”
为何高速下力矩衰减严重且极易出现波形畸变？这受限于“电机电感”与“12V 供电”的物理冲突：
在最大转速 (291RPM) 下，单步周期仅为 **0.51 ms**。但高达 8.2mH 的电感导致电气时间常数高达 **0.88 ms**。留给驱动器向线圈充磁的时间极其短暂，加上高速时巨大的反电动势 (BEMF) 抵消了大部分 12V 供电，导致电流根本无法在单步内爬升到位。
**结论**：“高电感 + 12V + 高转速”对 TMC5272 的电流斩波算法提出了极其苛刻的要求。参数稍有不慎，正弦波形即刻崩溃。

## 2. 动力学定性：彻底排除“失步”，锁定“电磁激振”

结合空载测试（卸下镜头）的反馈，系统的声学症结得到了彻底澄清：
卸下镜头意味着机械惯量降为零，空载匀速仅需约 3.6mN.m 的力矩，200mA 电流绝对绰绰有余。在**不可能失步**的空载状态下依然发出巨大的“嗡嗡”声。

**终极定性**：这**彻底排除了“力矩不足导致机械失速共振”的猜想**。这属于典型的**纯电控波形畸变引发的电磁激振**。劣质的电流锯齿波疯狂敲击毫无阻力的空载转子，引起转子高频振荡，爆发出共鸣噪声。

## 3. 挑战 NC-25 噪声认证专项应对策略

NC-25（相当于环境底噪约 30-35 dBA）是极为严苛的声学标准。针对 TMC5272 的底层架构，必须执行以下苛刻的协同调优：

| 降噪维度 | TMC5272 专属极限优化措施 | 预期效果 |
| :--- | :--- | :--- |
| **波形平滑** | **深调 SpreadCycle (`CHOPCONF`)**：修复 `TOFF` 过短导致的过零点交越畸变，恢复完美正弦波。 | 直接消灭空载/匀速段最吵人的低沉“嗡嗡”声。 |
| **加减速算法** | **启用 8-Point Ramp 并配置 `TVMAX`**：利用 8点曲线，并设定 `TVMAX > 0` 强制插入匀速防冲击段。 | 彻底抹除起步/停止时的硬核“咯噔”冲击声。 |
| **切换冲击** | **启用相位自动补偿 (`sg_angle_offset=1`)**：消除 StealthChop 到 SpreadCycle 切换时的 BEMF 相位跳变。 | 完美隐藏中段加速时换挡诱发的电磁抖动共振。 |
| **电流标定** | **微调至 250mA 左右 (`GLOBALSCALER`)**：200mA 易失真，400mA 激振大。250mA 是静音黄金点。 | 适度增加定子磁场刚性，压制微小纹波震荡。 |

## 4. 软件底层降噪与寄存器深度调试指南

### 4.1 运动控制：配置 8-Point Ramp 伪 S 曲线
TMC5272 并未使用传统的 BOW 寄存器，而是采用了精度更高的 8-Point Ramp（八点加减速发生器）。
* **应对机械冲击的绝招**：为了消除极高分辨率下的加速度突变（Jerk），必须在 `M0_TVMAX` (0x26) 寄存器中设定一个大于 0 的值。这会强制控制器在加减速切换的拐角处插入一段“微小匀速段”，将梯形波生硬的棱角“磨平”，达到 S 曲线般顺滑起步的效果（参考手册 Page 62）。

### 4.2 终结切换“咯噔”声：`sg_angle_offset` 与 `TPWMTHRS`
* **痛点**：目前在云台加速中段（约 30°/S）时切换斩波模式，会爆发出“咯噔”异响。手册 Page 44 指出，这是由于高速下 BEMF 导致电压与电流出现高达 90° 的相位差所致。
* **TMC5272 独家解法**：
  必须写入 `M0_SG4_THRS` (0x3F) 寄存器，将 bit 9 (`sg_angle_offset`) 置为 `1`。这会调用芯片内部的 StallGuard4 自动测量相位差，并在切入 SpreadCycle 时**自动补偿相位跳变**，实现真正的无缝换挡！
* **阈值建议**：配合上述补偿，将 `TPWMTHRS` 对应的速度阈值下调至 10°/S 左右，让系统在低速（BEMF尚小）时就平滑切入 SpreadCycle。

### 4.3 终结“嗡嗡”声：深度调校 SpreadCycle 波形畸变
结合电机 8.2mH 的极高电感，当前代码中的 `TOFF = 2` 是引发“嗡嗡”声的罪魁祸首。衰减时间太短，电感内的电流无法归零，导致严重的过零点畸变。必须放宽 `TOFF`，给电感充足的泄放时间。

**推荐的 `CHOPCONF` 寄存器 (0x38) 修改方案**：
```c
// 1. 放宽 TOFF，让高电感有时间泄放电流 (推荐 TOFF = 4 或 5)
TMC5272_FIELD_WRITE(TMC5272_M0_CHOPCONF, TMC5272_CHOPCONF_TOFF_MASK, TMC5272_CHOPCONF_TOFF_SHIFT, 5);

// 2. 配合放大的 TOFF，适当增加迟滞容差，紧密包裹正弦波纹波
// HSTRT 寄存器写 4 (实际值为 5)
TMC5272_FIELD_WRITE(TMC5272_M0_CHOPCONF, TMC5272_CHOPCONF_HSTRT_TFD210_MASK, TMC5272_CHOPCONF_HSTRT_TFD210_SHIFT, 4);
// HEND 寄存器写 0 (实际值为 -3)，总滞环 = 5 + (-3) = 2
TMC5272_FIELD_WRITE(TMC5272_M0_CHOPCONF, TMC5272_CHOPCONF_HEND_OFFSET_MASK, TMC5272_CHOPCONF_HEND_OFFSET_SHIFT, 0);

// 3. TBL 消隐时间保持默认的 2 (36 clocks)，对高电感较友好
TMC5272_FIELD_WRITE(TMC5272_M0_CHOPCONF, TMC5272_CHOPCONF_TBL_MASK, TMC5272_CHOPCONF_TBL_SHIFT, 2);
```

### 4.4 若斩波调校无效的“终极验尸” (纠正官方寄存器逻辑)

如果调节斩波参数没有实质改变，我们需要强制隔离单一模式，查杀是否存在“模式高频横跳 (Jitter)”的 Bug。

> **⚠️ 特别纠正：基于 TMC5272 手册 Page 44/46 的底层逻辑**
> `TPWMTHRS` 比较的是 **`TSTEP` (速度的倒数)**。条件是 `TSTEP >= TPWMTHRS` 时，StealthChop2 开启。

*   **强制全程 StealthChop2 (杀掉高速 SpreadCycle)**：
    将 `TPWMTHRS` 设为 `0x00`。因为 `TSTEP` 永远 `≥ 0`，所以系统会**永远锁定在静音模式**。（这解释了为什么之前设为 0 时，你依旧调不动 SpreadCycle，因为你根本就没切进去！）
*   **强制全程 SpreadCycle (杀掉静音模式) —— 终极查杀手段**：
    **绝不能通过改 `TPWMTHRS` 来实现！** 必须修改 `GCONF` 寄存器 (0x00)，将 `en_pwm_mode` (bit 0 对应电机0) **清零 (置为0)**。这会在硬件底层彻底关闭 StealthChop2。
    
    *验证法*：将 `en_pwm_mode = 0` 后，如果空载的高频嗡嗡声瞬间消失，或者原本无效的斩波参数(`TOFF`)终于生效了，彻底证实了系统在此前匀速 100°/s 时，遭受了致命的底层模式高频震荡干涉！

## 5. 总结：TMC5272 驱动深度降噪实施路线图

1. **查杀横跳 Bug**：第一时间在固件初始化中将 `GCONF` 寄存器的 `en_pwm_mode` 设为 `0`，强制单跑 SpreadCycle 测试。如果参数能调动了，说明元凶是模式阈值判定逻辑受了干扰。
2. **重塑加速曲线**：务必使用 TMC5272 独有的 **8-Point Ramp**，并赋予 `TVMAX` 一个非零值（例如 `0x1000`），强制插入匀速缓冲段，解决起步和停止瞬间的机械冲击声。
3. **前置并补偿模式切换**：恢复 `en_pwm_mode = 1` 后，务必将 `M0_SG4_THRS` 的 **`sg_angle_offset` 置为 `1`**（开启相位补偿），并将 `TPWMTHRS` 换算至 10°/S 对应的 `TSTEP` 值，完美隐藏切换冲击。
4. **示波器精调斩波**：针对 8.2mH 高感电机，放大 `TOFF`（4~5），优化 `HSTRT/HEND`，彻底消灭因电流饥饿和过零点交越引发的高频锯齿激振噪声。
5. **寻优“黄金电流”**：放弃 200mA 和 400mA 极端值，利用 `GLOBALSCALER` 将实际相电流微调至 **250mA - 280mA** 之间，压制微观振荡。
