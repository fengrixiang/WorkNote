# 云台预置位精度测试方法

## 测试目的

验证云台从任意位置调用预置位（Preset）后，光轴指向与首次设定位置的偏差，评估云台的**重复定位精度**与**长期稳定性**。

预置位精度是衡量云台机械结构、电机驱动（[MS35774](/docs/monitor/ms35774)、[TMC5272](/docs/monitor/tmc5272)）、回零策略与控制算法综合表现的关键指标。

## 基本概念

| 术语 | 定义 |
| ---- | ---- |
| 预置位（Preset） | 用户预先记录的水平/垂直角度位置，可通过编号一键调用 |
| 重复定位精度 | 多次调用同一预置位时，实际位置与目标位置的偏差最大值 |
| 绝对定位精度 | 实际位置与设定角度坐标的绝对偏差 |
| 回程差（Backlash） | 从正反两个方向逼近同一目标位时的位置差 |
| 漂移（Drift） | 长时间运行或温度变化后，预置位位置的累计偏移量 |

> 监控行业一般以**重复定位精度**作为核心验收指标，典型要求 ≤ 0.1°（高端球机可达 ≤ 0.05°）。

## 测试原理

**核心思想：** 在远距离屏幕/标靶上观察镜头指向，将云台的角度偏差放大为线性距离，便于测量。

```text
角度偏差 (°) = arctan(线性偏差 mm / 距离 mm) × 180 / π
```

**距离与精度对应关系：**

| 测试距离 | 0.1° 对应偏差 | 0.05° 对应偏差 | 0.01° 对应偏差 |
| -------- | ------------- | -------------- | -------------- |
| 5 m      | 8.7 mm        | 4.4 mm         | 0.87 mm        |
| 10 m     | 17.5 mm       | 8.7 mm         | 1.75 mm        |
| 20 m     | 34.9 mm       | 17.5 mm        | 3.49 mm        |
| 50 m     | 87.3 mm       | 43.6 mm        | 8.73 mm        |

> 测试距离越远，相同角度偏差对应的线性偏差越大，测量分辨率越高。但同时受空气扰动、标靶变形等环境因素影响也越大。

## 测试方法

### 方法一：激光打点法（推荐）

**原理：** 在云台镜头光轴方向同轴安装激光指示器，在远距离白板上记录光斑位置。

**设备：**

- 同轴激光器（5 mW 红外/绿色，发散角 < 1 mrad）
- 米格白板（5 m × 5 m，间距 1 mm 刻度）
- 测距仪（精度 ±1 mm）
- 三脚架（固定云台基座）

**优点：** 直观、低成本、可视化好  
**缺点：** 受激光器安装同轴度影响，远距离光斑发散

### 方法二：图像识别法（十字标靶法）

**原理：** 镜头对准带十字刻度的标靶，通过视频帧分析十字中心在画面中的像素偏移，反算角度偏差。

**设备：**

- 高对比度十字标靶（黑底白十字 / ChArUco 板）
- 测试 PC（OpenCV 进行模板匹配 / 角点检测）
- RTSP/HDMI 视频采集卡

**像素 → 角度换算：**

```text
单像素对应角度 (°/pixel) = 镜头水平视场角 (HFOV) / 图像宽度 (pixel)
角度偏差 = 像素偏差 × (HFOV / 图像宽度)
```

**示例：** 1920 × 1080 分辨率，HFOV = 60°，单像素 ≈ 0.031°，子像素插值后可达 0.005° 分辨率。

**优点：** 自动化、可批量测试、不需要额外标定光源  
**缺点：** 受镜头畸变、对焦清晰度影响，需做畸变标定

### 方法三：陀螺仪法

**原理：** 在云台运动部件（云台机芯）上加装高精度陀螺仪/IMU，记录角度数据。

**设备：**

- MEMS IMU（如 BMI088、ICM-42688，零偏稳定性 < 5 °/h）
- 数据采集板（≥ 1 kHz 采样）

**优点：** 不依赖外部环境，可直接读取绝对角度  
**缺点：** 长时间累计漂移；安装位置受限；与 [VX630A VS VX720 速度测试](/docs/monitor/VX630A_VS_VX720)同类设备

### 方法四：编码器/光栅尺法（实验室级）

**原理：** 在云台水平/垂直旋转轴上加装绝对值编码器（如 17 位光电编码器，分辨率 0.0027°），直接读取轴角度。

**优点：** 精度最高（可达 ±0.005°）  
**缺点：** 需改装机械结构、成本高，一般用于产品验证阶段

## 测试步骤

### 1. 测试前准备

- 云台水平架设，使用水平仪校准基座，倾角 < 0.1°
- 镜头变焦至最长焦端（放大角度偏差，提升测量灵敏度）
- 云台预热 ≥ 15 分钟（[MS35774](/docs/monitor/ms35774_drive) 与 [TMC5272](/docs/monitor/tmc5272_drive) 驱动芯片温度稳定后定位漂移减小）
- 关闭风扇、空调直吹（避免镜头/标靶气流扰动）

### 2. 预置位标定

1. 通过协议（[Pelco-D](/docs/protocol/pelco_d) / [Pelco-P](/docs/protocol/pelco_p) / [ONVIF](/docs/protocol/onvif)）将云台运动至目标位置
2. 调用"设置预置位"指令，存储为 Preset #1
3. 记录此时的初始光斑/十字位置作为基准点 P₀

### 3. 单点重复精度测试

对同一个预置位（如 Preset #1）执行以下循环 **30 次**：

```text
For i = 1 to 30:
    云台随机移动到 ±30° 范围内任意位置
    停顿 2 s
    调用 Preset #1
    停顿 2 s（待机械稳定）
    记录光斑/十字位置 Pi（水平 H, 垂直 V）
End
```

**重复精度计算：**

```text
ΔHi = Hi - H₀       (水平偏差)
ΔVi = Vi - V₀       (垂直偏差)

水平重复精度 = max(|ΔHi|) , i = 1..30
垂直重复精度 = max(|ΔVi|) , i = 1..30

或采用 3σ 准则：
精度 = 3 × σ(ΔHi)   (95% 置信区间)
```

### 4. 多点遍历测试

设置 8 个分布均匀的预置位（每 45° 一个），按以下序列调用，每个预置位测试 10 次：

```text
P1 → P3 → P5 → P7 → P2 → P4 → P6 → P8 → P1 ...
```

> 跳跃式遍历可暴露**长行程定位**与**回程差**问题。

### 5. 回程差测试

- 从顺时针方向逼近 Preset #1，记录 30 次位置 → 均值 H_cw
- 从逆时针方向逼近 Preset #1，记录 30 次位置 → 均值 H_ccw

```text
回程差 = |H_cw - H_ccw|
```

> 回程差主要来源于齿轮间隙、皮带松紧、电机失步。使用 [TMC5272 的 StallGuard 堵转检测](/docs/monitor/tmc5272_debug)优化回零策略可降低此项偏差。

### 6. 长期漂移测试

每隔 1 小时调用一次 Preset #1，连续测试 24 小时，记录位置漂移曲线：

```text
漂移量 (t) = P(t) - P(0)
```

观察是否存在温度相关漂移、累计步进失步等问题。

## 数据记录模板

| 测试编号 | 时间 | 调用前位置 (°) | 目标位置 (°) | 实测光斑 H (mm) | 实测光斑 V (mm) | ΔH (mm) | ΔV (mm) | Δ角度 (°) |
| -------- | ---- | -------------- | ------------ | --------------- | --------------- | ------- | ------- | --------- |
| 1        |      |                |              |                 |                 |         |         |           |
| 2        |      |                |              |                 |                 |         |         |           |
| ...      |      |                |              |                 |                 |         |         |           |

**统计字段：**

- 平均偏差（Mean）
- 标准差（σ）
- 最大偏差（Max）
- 3σ 重复精度
- 回程差
- 24 h 漂移

## 验收标准（建议值）

| 指标 | 消费级 | 商用级 | 高端球机 |
| ---- | ------ | ------ | -------- |
| 水平重复精度 | ≤ 0.5° | ≤ 0.1° | ≤ 0.05° |
| 垂直重复精度 | ≤ 0.5° | ≤ 0.1° | ≤ 0.05° |
| 回程差 | ≤ 0.3° | ≤ 0.1° | ≤ 0.03° |
| 24 h 漂移 | ≤ 1.0° | ≤ 0.2° | ≤ 0.05° |

## 影响精度的关键因素

| 类别 | 因素 | 优化方向 |
| ---- | ---- | -------- |
| **机械** | 齿轮间隙、皮带打滑、轴承游隙 | 减小回程差预紧、采用谐波减速器 |
| **电机驱动** | 失步、微步细分精度、电流纹波 | 使用 [TMC5272](/docs/monitor/tmc5272) 的 256 微步 + StealthChop2 |
| **回零策略** | 上电零点偏差 | 加装霍尔零点开关或绝对编码器 |
| **温度** | 电机/驱动板温漂、机械热膨胀 | 预热补偿、温度闭环 |
| **算法** | 加减速曲线突变、PID 超调 | S 曲线加减速、抗积分饱和 |
| **测试环境** | 三脚架振动、标靶移动、激光发散 | 水泥地基、刚性安装、缩短测试距离 |

## 自动化测试脚本

参考 [云台测试脚本](/docs/monitor/python) 中的串口/RTSP 实现，可扩展为预置位精度自动化测试：

```python
# 伪代码
import cv2, time, statistics

results_h, results_v = [], []
for i in range(30):
    ptz.move_random()           # 随机移动
    time.sleep(2)
    ptz.call_preset(1)          # 调用预置位
    time.sleep(2)
    frame = capture_frame()     # 抓取一帧
    h, v = detect_cross(frame)  # 检测十字中心
    results_h.append(h)
    results_v.append(v)

print("水平 3σ 精度:", 3 * statistics.stdev(results_h))
print("垂直 3σ 精度:", 3 * statistics.stdev(results_v))
```

## 注意事项

1. **测试距离** 推荐 5 ~ 20 m，过近受发散角影响，过远受气流影响
2. **变焦档位** 测试前固定焦距（最长焦端最敏感），中途不可变焦
3. **预热时间** 冷机直接测试结果偏差大，应在 [MS35774 速度表](/docs/monitor/ms35774_speed)推荐的稳定工作区间内
4. **协议延迟** ONVIF/Pelco 命令响应时间不一致，应在云台真正停止后再记录位置
5. **样本数量** 单点测试 ≥ 30 次才有统计意义，全程遍历 ≥ 100 次
6. **多档速度** 不同 [云台速度档位](/docs/monitor/VX630A_VS_VX720)下的精度可能差异显著，应分别测试低/中/高三档
7. **机械稳定** 三脚架/支架的微小振动直接体现在测试结果中，必要时使用配重或地脚螺栓固定
