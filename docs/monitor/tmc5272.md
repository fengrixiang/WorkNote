# TMC5272 八点斜坡（8-Point Ramp）原理与使用指南

> 本文基于 **TMC5272** 数据手册编写。TMC5272 是 ADI 的一款双轴步进电机控制器/驱动器，内置两个 8 点斜坡发生器，支持 2.1V-20V，每轴 0.8A RMS。

参考资料：[TMC5272 Datasheet (PDF)](https://www.analog.com/media/en/technical-documentation/user-guides/tmc5272_datasheet.pdf)

## 1. 什么是八点斜坡

传统的步进电机加减速使用简单的梯形速度曲线（恒定加速度），而 TMC5272 的 **8 点斜坡发生器** 允许将运动曲线分为 **3 段加速 + 3 段减速**，外加起始速度和停止速度，共 8 个可编程关键点。这样可以：

- 适配步进电机的高频扭矩衰减特性（高速时降低加速度）
- 实现**伪 S 形曲线**，减小加减速过程中的抖动（jerk）
- 最大化利用电机扭矩，缩短运动时间

## 2. 八点斜坡速度曲线

```plaintext
速度 Velocity ▲
              │
              │                    ─────────────────
              │                   /                 \
              │                  /                   \
     V2 ──────┼─────────────────/                     \──────── V2
              │                /                       \
              │               /                         \
     V1 ──────┼──────────────/                           \────── V1
              │             /                             \
              │            /                               \
VSTART ───────┼───────────/                                 \──── VSTOP
              │
              └───────────────────────────────────────────────────────▶ 时间 Time
                  
           【加速区间】                匀速平台               【减速区间】
        A1      A2      AMAX        TVMAX 保持时间       DMAX     D2      D1
     低速加速  中速加速  高速加速                     高速减速  中速减速  低速减速

```

### 2.1 八个关键参数

| 参数 | 方向 | 含义 |
| ------ | ------ | ------ |
| **VSTART** | - | 起始速度，跳过低速共振区 |
| **A1** | 加速 | VSTART → V1 的加速度 |
| **V1** | - | 第一个速度阈值 |
| **A2** | 加速 | V1 → V2 的加速度 |
| **V2** | - | 第二个速度阈值 |
| **AMAX** | 加速 | V2 → VMAX 的加速度 |
| **VMAX** | - | 最大目标速度 |
| **DMAX** | 减速 | VMAX → V2 的减速度 |
| **D2** | 减速 | V2 → V1 的减速度 |
| **D1** | 减速 | V1 → VSTOP 的减速度 |
| **VSTOP** | - | 停止速度（建议 ≥ 100） |
| **TVMAX** | - | 匀速段最短持续时间（减小 jerk） |
| **TZEROWAIT** | - | 速度过零等待时间 |

其中，加速 3 段（A1, A2, AMAX）+ 减速 3 段（D1, D2, DMAX）+ VSTART + VSTOP = **八点**。

## 3. 原理详解

### 3.1 为什么要多段加速

步进电机的输出扭矩随转速升高而下降（反电动势增大），如果全程使用恒定高加速度，高速时容易失步。八点斜坡允许：

```text
  扭矩
   ▲
   │████████████████████
   │████████████████     ← A1（低速，扭矩充足，可以高加速）
   │████████████         ← A2（中速，扭矩中等）
   │████████             ← AMAX（高速，扭矩衰减，必须低加速）
   │████
   │██
   │
   └──────────────────────────→ 转速
         低速       中速       高速
```

### 3.2 为什么要多段减速

系统摩擦力在减速方向起辅助作用，因此减速可以比加速更快：

```text
  速度
   ▲
   │         ╱╲          加速段（缓）：A1 < A2 < AMAX
   │       ╱    ╲
   │     ╱        ╲      减速段（急）：D1 > D2 > DMAX
   │   ╱            ╲
   │ ╱                ╲
   │╱      ↕ 摩擦力    ╲    减速可以更陡，因为摩擦力辅助制动
   └────────────────────→ 时间
     加速           减速
```

### 3.3 TVMAX 的作用（Jerk 抑制）

当运动距离不够到达 VMAX 时，加速段直接过渡到减速段会产生较大的加速度突变（jerk）。TVMAX 参数强制在加速→减速之间插入一段最小持续时间的匀速段，实现伪 S 形过渡：

```text
  速度                     速度
   ▲                       ▲
   │      ╱╲               │      ╱──╲
   │    ╱    ╲             │    ╱      ╲
   │  ╱        ╲           │  ╱   匀速   ╲
   │╱            ╲         │╱    ────     ╲
   └──────────────→ t      └──────────────→ t

  TVMAX = 0               TVMAX > 0
  尖角过渡，jerk 大        插入匀速段，过渡平滑
  加速度瞬间反向           加速度缓慢反向，抖动小
```

## 4. 不同距离下的曲线形态

### 4.1 距离足够（完整八点曲线）

```text
    速度
     ▲
     │           ┌──────┐
     │         ╱╱│      │╲╲
     │       ╱╱  │ AMAX │  ╲╲
  V2 ┼─────╱╱───┤      ├───╲╲────
     │   ╱╱  A2 │      │ D2   ╲╲
  V1 ┼─╱╱───────┤      ├───────╲
     │╱     A1  │      │   D1    ╲
     └──────────┴──────┴──────────→ t
        加速      匀速      减速
```

### 4.2 距离不够到达 VMAX

VMAX 被自动降低为 VMAX'，保持 TVMAX 匀速段：

```text
    速度
     ▲
     │        ┌────┐
     │      ╱╱│    │╲╲
     │    ╱╱  │    │  ╲╲        VMAX' < VMAX
  V1 ┼──╱╱───┤    ├───╲╲──     自动降低峰值
     │╱   A1 │    │ D1  ╲
     └───────┴────┴──────────→ t
        加速  匀速   减速
```

### 4.3 距离非常短

V1/V2 都无法到达，仅使用 A1 加速后立即减速：

```text
    速度
     ▲
     │       ╱╲
     │     ╱    ╲
     │   ╱   A1   ╲ D1
     │ ╱            ╲
     │╱                ╲
     └──────────────────→ t
        加速      减速
```

## 5. 寄存器配置

TMC5272 每个电机轴有独立的斜坡寄存器，Motor 0 使用 `0x1B-0x28`，Motor 1 使用 `0x50-0x5D`。

### 5.1 寄存器地址表（Motor 0）

| 地址 | 寄存器 | 说明 |
| ------ | ------ | ------ |
| 0x1B | M0_VSTART | 起始速度 |
| 0x1C | M0_A1 | 第一段加速度 |
| 0x1D | M0_V1 | 第一速度阈值 |
| 0x1E | M0_A2 | 第二段加速度 |
| 0x1F | M0_V2 | 第二速度阈值 |
| 0x20 | M0_AMAX | 最大加速度 |
| 0x21 | M0_VMAX | 最大速度 |
| 0x22 | M0_DMAX | 最大减速度 |
| 0x23 | M0_D2 | 第二段减速度 |
| 0x24 | M0_D1 | 第一段减速度 |
| 0x25 | M0_VSTOP | 停止速度 |
| 0x26 | M0_TVMAX | 匀速段最短时间 |
| 0x27 | M0_TZEROWAIT | 过零等待时间 |
| 0x28 | M0_XTARGET | 目标位置 |

### 5.2 单位换算

所有速度和加速度参数均以内部时钟为基准：

| 参数 | 公式 | 单位 |
| ------ | ------ | ------ |
| 微步速度 | v[Hz] = v[TMC5272] × fCLK / 2^24 | microsteps/s |
| 微步加速度 | a[Hz/s] = a[TMC5272] × fCLK^2 / 2^41 | microsteps/s^2 |
| TSTEP | TSTEP = fCLK / (fSTEP × 256/USC) | 时钟周期数 |

USC = 微步分辨率（通常 256），FSC = 每圈整步数（通常 200）。

## 6. 使用示例

### 6.1 速度模式（简单场景）

速度模式下只使用 AMAX 和 VMAX：

```c
// 设置为速度模式（正方向）
writeRegister(RAMPMODE, 0x01);  // M0_RAMPMODE = 1 (velocity positive)

writeRegister(AMAX, 1000);     // 加速度
writeRegister(VMAX, 100000);   // 目标速度

// 停止：写 VMAX = 0
writeRegister(VMAX, 0);
```

### 6.2 位置模式（完整八点斜坡）

```c
// 1. 设置位置模式
writeRegister(RAMPMODE, 0x00);  // positioning mode

// 2. 配置斜坡参数
writeRegister(VSTART, 0);       // 起始速度为 0
writeRegister(A1, 500);         // 低速段加速度
writeRegister(V1, 20000);       // V1 阈值
writeRegister(A2, 300);         // 中速段加速度
writeRegister(V2, 50000);       // V2 阈值
writeRegister(AMAX, 200);       // 高速段加速度（最低）
writeRegister(VMAX, 100000);    // 最大速度
writeRegister(DMAX, 400);       // 高速段减速度
writeRegister(D2, 600);         // 中速段减速度
writeRegister(D1, 800);         // 低速段减速度
writeRegister(VSTOP, 1000);     // 停止速度（不要设为 0）
writeRegister(TZEROWAIT, 100);  // 过零等待
writeRegister(TVMAX, 0);        // 禁用 jerk 抑制（设 > 0 启用）

// 3. 设置目标位置（触发运动）
writeRegister(XTARGET, 500000);
```

### 6.3 伪 S 形曲线配置

将 A1/D1 设低、A2/D2 设高，配合 TVMAX > 0：

```c
writeRegister(A1, 200);     // 低起步加速度
writeRegister(A2, 500);     // 中等加速
writeRegister(AMAX, 800);   // 高加速冲刺
writeRegister(DMAX, 800);
writeRegister(D2, 500);
writeRegister(D1, 200);     // 低停止减速度
writeRegister(TVMAX, 500);  // 强制匀速段，减小 jerk
```

对应速度曲线：

```text
    速度
     ▲
     │             ┌────────────┐
     │           ╱╱│            │╲╲
     │         ╱╱  │   AMAX     │  ╲╲
     │       ╱╱    │            │    ╲╲
     │     ╱╱  A2  │            │ D2   ╲
     │   ╱╱        │            │       ╲
     │ ╱╱     A1   │            │   D1    ╲
     │╱            │            │          ╲
     └─────────────┴────────────┴────────────→ t
        加速          匀速          减速
```

### 6.4 运行中修改参数

所有斜坡参数可以在运动过程中实时修改：

```c
// 修改目标位置（运动中）
writeRegister(XTARGET, newTarget);

// 修改最大速度（运动中减速/加速）
writeRegister(VMAX, newVMAX);

// 紧急停止：将 XACTUAL 复制到 XTARGET
writeRegister(XTARGET, readRegister(XACTUAL));
```

## 7. 注意事项

1. **VSTOP 不能设为 0**：位置模式下 VSTOP 最小建议 100-1000，否则无法精确停在目标位置
2. **VSTOP >= VSTART**：确保短距离运动也能正常停止
3. **D1/D2 不要设为 0**：位置模式下 D1 和 D2 必须大于 0
4. **D2 复位默认值为 10**：已经有一个合理的非零默认值
5. **速度模式只用 AMAX**：A1/A2/D1/D2/D2 在速度模式下不使用
6. **TVMAX = 0 禁用 jerk 抑制**：设为 > 0 才启用匀速段
7. **TZEROWAIT**：避免从 VSTOP 瞬间反向加速到 -VSTART 造成的过大 jerk
