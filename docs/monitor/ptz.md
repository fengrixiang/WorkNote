# 云台速度与电机速度

## 基础概念与换算

RPM（Revolutions Per Minute）即每分钟转数，是衡量旋转物体转速的常用单位。

**换算关系：**

- 1 RPM = 1 转/分钟
- 1 转/秒 = 60 RPM
- 1 RPM = 6°/秒（一圈 = 360°，360° / 60 秒 = 6°/秒）

**常用换算：**

| RPM  | 角速度（°/秒） |
| ---- | -------------- |
| 10   | 60             |
| 60   | 360            |
| 67.5 | 405            |

## 计算公式

云台系统中涉及以下关键参数：

- 云台输出速度：90°/秒
- 减速比：4.5:1

**核心公式：**

```text
电机角速度 (°/s) = 云台速度 (°/s) × 减速比
电机转速 (RPM)   = (电机角速度 (°/s) / 360) × 60
```

**计算示例：**

```text
电机角速度 = 90°/s × 4.5 = 405°/s
电机转速   = (405 / 360) × 60 = 67.5 RPM
```

即电机每分钟转 67.5 圈。

## 不同转速下的计算与 StallGuard4 可用性

| 云台速度 | 电机角速度 | 电机转速  | StallGuard4                                |
| -------- | --------- | -------- | ------------------------------------------ |
| 1°/s     | 4.5°/s    | 0.75 RPM | 几乎失效（超低速，反电动势太小）            |
| 90°/s    | 405°/s    | 67.5 RPM | 可用（中低速，SpreadCycle 模式下）          |
| 180°/s   | 810°/s    | 135 RPM  | 高度可靠（中高速）                          |

## MS35774 vs TMC5272 驱动芯片对比

### 芯片概览

| 对比项 | MS35774 | TMC5272 |
|--------|---------|---------|
| **厂商** | 瑞盟科技 (Hangzhou Ruimeng) | Analog Devices (Trinamic) |
| **电机通道** | 单轴（1 × 两相） | 双轴（2 × 两相） |
| **驱动电压** | 5.5V ~ 36V | 2.1V ~ 20V |
| **输出电流** | 峰值 2A，连续 1.4A | 峰值 0.8A RMS/线圈 |
| **导通电阻** | 570mΩ | 310mΩ |
| **最大细分** | 256 微步（内部） | 256 微步 |
| **运动接口** | STEP/DIR（2/4/8/16 细分可选） | 无 STEP/DIR，内置运动控制器 |
| **通信接口** | SPI（配置寄存器） | SPI + 单线 UART |
| **静音技术** | 电流微细分 + 扭矩纹波修正 | StealthChop2（超静音 PWM） |
| **斩波算法** | 基础斩波 | SpreadCycle（自适应快/慢衰减） |
| **堵转检测** | 无 | StallGuard（无传感器负载检测） |
| **节能技术** | 无 | CoolStep（负载自适应电流，节能 75%） |
| **内置运动控制器** | 无（需外部 MCU 生成脉冲） | 有（内置斜坡发生器，可脱离 MCU 独立运动） |
| **编码器接口** | 无 | 有 |
| **Pin 兼容** | 与 TMC2208/TMC2225 Pin-to-Pin | 独立封装 |
| **保护功能** | 过温/欠压/过流/短路 | 过温/欠压/过流/短路 |
| **典型应用** | 监控 PTZ 云台、3D 打印机 | 电池供电设备、便携医疗、机器人、IoT |

### 核心差异

1. **集成度**：TMC5272 是双轴 + 内置运动控制器，可脱离 MCU 独立完成加减速运动；MS35774 是单轴纯驱动，需 MCU 持续发送 STEP 脉冲
2. **智能化**：TMC5272 有 StallGuard（无传感器堵转检测）和 CoolStep（自适应节能），MS35774 没有这些高级功能
3. **功率**：MS35774 电流更大（2A）、电压更宽（36V），适合监控云台等中等功率场景；TMC5272 功率较低（0.8A/20V），定位电池供电便携设备
4. **静音**：两者都支持 256 微步细分实现低噪声，但 TMC5272 的 StealthChop2 在低速静音方面更成熟
5. **生态**：MS35774 Pin 兼容 TMC2208，可做国产替代；TMC5272 是 Trinamic 生态，软件和文档更完善
