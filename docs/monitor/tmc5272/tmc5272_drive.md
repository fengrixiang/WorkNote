# TMC5272 云台控制技术文档



## 1. 硬件链路

```text
AT32F413 MCU
  ├── SPI2 ──→ TMC5272 #0 (M0 = Tilt 垂直电机，软件CS)
  ├── SPI2 ──→ TMC5272 #1 (M1 = Pan 水平电机，软件CS)
  ├── PB12 (HB) ──→ 水平光耦 (位置零点检测)
  ├── PB7  (VB) ──→ 垂直光耦 (位置零点检测)
  └── MOTOR_SLEEP_PIN ──→ 电机休眠控制
```

> **注意**：M0 = Tilt（垂直），M1 = Pan（水平），TMC5272 是双电机驱动芯片，一片驱动两个步进电机。

## 2. 软件架构

### 2.1 分层架构

```text
┌─────────────────────────────────────────────┐
│  命令入口层 (command.c / ir.c)              │
│  VISCA/Pelco/红外 → PT_Move_xxx() /         │
│                      PT_Pan_Preset() /       │
│                      PT_Tilt_Preset()        │
├─────────────────────────────────────────────┤
│  云台状态机 (tmc5272_pt.c)                   │
│  PT_CTL 结构体管理 pan/tilt 双轴            │
│  PT_MODE × PT_STATE 二维状态驱动            │
├─────────────────────────────────────────────┤
│  运动参数计算 (tmc5272_pt.c)                 │
│  M0_Motion() / M1_Motion()                  │
│  → Get_Motor_Suitable_Ramp_Param()          │
│  → Mx_Ramp_Position_Mode_Move_Param_Write() │
├─────────────────────────────────────────────┤
│  SPI 寄存器读写 (tmc5272_pt.c)              │
│  Tmc5272_Reg_Write() → SPI_SendData()       │
│  Tmc5272_Reg_Read()  → SPI_ReadData()       │
└─────────────────────────────────────────────┘
```

### 2.2 主循环执行顺序

`user_main.c:73-134` `while(1)` 循环中，按以下顺序执行各任务：

```text
1. Gsensor_Task()          // G传感器
2. Uart1_Command_Process()  // SOC命令处理（需要init_finish）
3. P_V_Report_Task()        // AI实时上报（位置+速度）
4. Pos_Report_Task()        // Free-D实时上报（仅位置）
5. Motor_Drv_Task()         // 电机驱动执行
6. Tmc5272_Pt_Task()        // 云台状态机
7. IR_Task()                // 红外
8. Usart3/Uart4_Polling     // RS-485/232
```

`Motor_Drv_Task()` 在 `Tmc5272_Pt_Task()` 之前执行，确保状态机读取到的位置/速度是最新的运动执行结果。

## 3. 初始化与自检流程

### 3.1 上电启动序列

```text
user_main_func()
  ├── My_PT_Init()              ← 寄存器初始化
  ├── delay_sec(2)              ← 等待硬件稳定
  └→ while(1) {
        if(init_finish) { Uart1_Command_Process(); 上报任务... }
        Motor_Drv_Task()        ← 首次执行：预计算表 + My_PT_Init() + 状态机
        Tmc5272_Pt_Task()       ← 云台状态机
        IR_Task(); ...
      }
```

`Motor_Drv_Task()` 首次执行时完成一次性初始化：预计算24级停止减速参数 + 预计算ppt速度匹配表 + `My_PT_Init()` + 标记 `dev_reg_init=TRUE`。

### 3.2 My_PT_Init() 初始化步骤

| 步骤 | 操作 | 说明 |
| ---- | ---- | ---- |
| 1 | 状态初始化 | `pt_mode=PT_RESET_MODE`，`pt_state=PT_PRE_INIT_STATE`，清零所有标志 |
| 2 | 轴参数初始化 | Pan/Tilt 各自设置：`opto=NO_TRIGGER`，`fsr_scale=2`，`fsr_range=3`，`p_min/p_max` |
| 3 | TMC5272寄存器批量初始化 | `Tmc5272_Reg_Init()` 按预设表写入110个寄存器，写后回读校验（最多重试5次） |
| 4 | 电机斩波/PWM参数 | `Minebea_Motor_Suitable_Param()` 配置CHOPCONF/PWMCONF（参数详见[12.3](#123-chopconf-斩波器配置美蓓亚电机)） |
| 5 | 双轴配置 | M0(Tilt)/M1(Pan)各自：FSR电流范围 → XACTUAL=XTARGET=p_min → 使能8段位置斜坡模式 |
| 6 | 电流 + 软件限位 | 写入 IHOLD_IRUN（详见[12.2](#122-ihold_irun-电流配置)），配置 VIRTUAL_STOP_L/R（详见[5.6](#56-软件限位)） |

### 3.3 复位自检状态机（RESET_MODE）

上电后自动执行的校准流程，由 `Tmc5272_Pt_Task()` 驱动。

> **PT_INIT_DISABLE** 宏：跳过光耦校准，直接设位置为 p_min 并通知 SOC（工装调试用）。

#### 状态转换总览

```text
PT_PRE_INIT_STATE  ──→  PT_INIT_STATE  ──→  PT_PRESET_STATE  ──→  PT_READY_STATUS
 (偏移+移向p_min)     (寻光耦零点)        (运动到Home)          (就绪)
```

**60秒超时保护**：`PT_PRE_INIT` 之外的状态超过60秒未完成 → 强制 `PT_NORMAL_MODE` + `init_finish=TRUE` + 通知 SOC。

#### PT_PRE_INIT_STATE

1. 记录自检开始时间 `t_reset_start`，指示灯绿亮红亮
2. 双轴 XACTUAL 设为 `p_min - 0.5°`（偏移确保不在光耦遮光区）
3. 双轴以速度等级9移向 p_min
4. → 转入 PT_INIT_STATE

#### PT_INIT_STATE（寻光耦零点）

Pan 和 Tilt 两轴独立并行执行，以 Pan 为例：

1. **向 p_max 运动**（速度等级10~12）寻找光耦
2. **光耦触发**（HB_IO_READ==SET）→ 停止，标记 `opto=TRIGGER`
3. **反向离开遮光区**（速度等级6），移向 `p_max - 8°`
4. **离开遮光区后停止**（HB_IO_READ==RESET）
5. **异常容错**：到达 p_max 仍未触发 → 后退16°重新搜索

双轴都触发且离开遮光区、双轴静止后：
- `Set_Pan_Position(p_max)` — 标记当前位置为 Pan 零点
- `Set_Tilt_Position(p_max - 5°)` — Tilt 零点带偏移
- → 转入 PT_PRESET_STATE，以速度等级 Pan=20 / Tilt=18 移向 Home

#### PT_PRESET_STATE（运动到Home）

- Home 位置：Pan = `p_max - 171°`，Tilt = `p_max - 87°`（标准）/ `p_max - 90°`（广电）
- 到达后：指示灯绿亮红灭 → `init_finish=TRUE` → `PT_NORMAL_MODE` → 通知 SOC（`0x81 0x0A 0x11 0xAA 0xFF`）→ `Print_Home_Pos()` 上报Home位置
- → PT_READY_STATUS

#### PT_ERROR_STATE

复位过程中的错误状态，当前为空实现（保留扩展）。

#### 初始化时序

```text
0s      2s                ~5s         ~8s         ~12s
│  delay│  PRE_INIT  INIT │  PRESET   │  READY    │
│  (2s) │  偏移+移动 寻光耦│  到Home   │  就绪     │
│       │  sp=9     sp=10 │  sp=20    │           │
│       │  LED:绿亮红亮    │绿亮红灭   │           │
        ↑                  ↑           ↑
   首次初始化          光耦触发完成   init_finish=TRUE
```

## 4. 命令运动流程

以 VISCA 命令 "Pan Right" 为例的完整调用链：

```text
① USART1 接收 → uart1_rec_command.c DMA缓冲区
② Uart1_Command_Process() → command.c VISCA命令解析
③ command.c:1636 调用 PT_Move_Right(speed)
④ PT_Move_Right():
   ├── pt->pan.v_target = Get_Pan_M_V_Rps(speed)   // 速度等级→RPS查表
   ├── pt->pan.x_target = pt->pan.p_max             // 方向=右→目标=p_max
   └── pt->pan.tar_refresh = TRUE                    // 设置刷新标志
⑤ 下一轮主循环 Motor_Drv_Task():
   ├── 检测 tar_refresh == TRUE
   └── M1_Motion(target, vrps, ramp)
       ├── Get_Motor_Suitable_Ramp_Param()           // 计算8段加减速参数
       │   ├── 根据v_rps计算V1/V2/VMAX（ppt单位）
       │   ├── 根据acc_dec_ref计算A1/A2/AMAX
       │   └── 考虑当前运动方向和速度进行参数适配
       ├── 跟踪模式→加速度减半
       └── M1_Ramp_Position_Mode_Move_Param_Write()  // 写入TMC5272寄存器
           ├── 写入15个寄存器（VSTART/A1/V1/A2/V2/AMAX/VMAX/DMAX/D2/D1/VSTOP/TVMAX/TZEROWAIT/XTARGET）
           └── 每个寄存器写后回读校验
⑥ TMC5272硬件自动执行8段加减速斜坡运动
```

## 5. 位置体系

### 5.1 运动范围定义

| 参数 | 宏定义 | 值 |
| ------ | -------- | ------ |
| 水平运动范围 | `H_MOTION_RANGE_PT` | 342°（-171° ~ +171°） |
| 垂直运动范围（标准） | `V_MOTION_RANGE_PT` | 112°（-30° ~ +82°） |
| 垂直运动范围（广电认证） | `V_MOTION_RANGE_PT` | 120°（NRTA_CERTIFICATION） |
| Pan 减速比 | `VX730_PT_PAN_TRANSMISSION_RATIO` | 4.5 |
| Tilt 减速比 | `VX730_PT_TILT_TRANSMISSION_RATIO` | 3.5 |

### 5.2 位置编码原理

TMC5272 使用 **ppt（pulses per tick）** 作为内部位置单位。位置体系基于以下物理量：

| 物理量 | 值 | 说明 |
| ------ | ---- | ---- |
| 电机步距角 | 0.9° | 即 400 步/圈 |
| 微步分辨率 | 256 | CHOPCONF 中 MRES 配置 |
| 微步数/圈 | 102400 | 400 × 256 |
| Pan 减速比 | 4.5 | 电机轴转4.5圈→输出轴转1圈 |
| Tilt 减速比 | 3.5 | 电机轴转3.5圈→输出轴转1圈 |

**位置换算推导**：

```text
ppt_per_deg（每度步数）= 102400 × 减速比 / 360
  Pan:  102400 × 4.5 / 360 = 1280 ppt/°
  Tilt: 102400 × 3.5 / 360 ≈ 995.29 ppt/°

含义：云台（输出轴）转1°，电机轴需要走的微步数
  Pan 1280 ppt = 1.25 整步 × 256 微步 → 电机轴转 1.25/400 圈 = 0.003125 圈
  输出轴转1° = 1/360 圈，电机轴转 4.5/360 = 0.0125 圈 ✓
```

### 5.3 位置计算公式

```text
基础公式：
  p_max = p_min + 102400 × 减速比 × 运动范围° / 360

Pan轴：
  p_min = 0x003D0000 = 3997696
  p_max = 3997696 + 102400 × 4.5 × 342 / 360
        = 3997696 + 437760
        = 4435456 (0x43AE40)
  每度步数 = 437760 / 342 ≈ 1279.47 ppt/°（实际公式值 1280）

Tilt轴（标准）：
  p_min = 0x003D0000 = 3997696
  p_max = 3997696 + 102400 × 3.5 × 112 / 360
        = 3997696 + 111473
        = 4109169
  每度步数 = 111473 / 112 ≈ 995.29 ppt/°
```

### 5.4 p_min 值分析

`p_min = 0x003D0000 = 3,997,696` 需满足以下约束：

| 约束 | 说明 |
| ---- | ---- |
| 负向余量 | 复位阶段设 `XACTUAL = p_min - 1°步数`，p_min 必须大于回退距离 |
| 正向不溢出 | `p_max = p_min + range_steps` 不能超过 `0x7FFFFFFF`（TMC5272 signed 32-bit） |
| 预置位一致 | 改 p_min 会导致已保存的绝对位置坐标偏移 |

**各方向可走距离**：

```text
向0方向（负向余量）：
  Pan:  3,997,696 / 1280 ≈ 3123° 输出轴 → 3123/360 ≈ 8.7 圈（输出轴）→ 8.7×4.5 ≈ 39 圈（电机轴）
  Tilt: 3,997,696 / 995  ≈ 4017° 输出轴 → 4017/360 ≈ 11.2 圈（输出轴）→ 11.2×3.5 ≈ 39 圈（电机轴）

向 0x7FFFFFFF 方向（正向余量）：
  Pan:  (2,147,483,647 - 4,435,456) / 1280 ≈ 1,676,000°
  Tilt: (2,147,483,647 - 4,109,169) / 995  ≈ 2,153,000°
```

实际需求仅 1° ~ 8° 的回退距离，`0x003D0000` 提供了远超需求的负向保护。

### 5.5 关键位置计算汇总

| 位置 | Pan | Tilt |
| ---- | --- | ---- |
| 最小限位 | `p_min = 0x003D0000` | `p_min = 0x003D0000` |
| 最大限位 | `p_min + 102400×4.5×342/360` | `p_min + 102400×3.5×112/360` |
| Home位置 | `p_max - 171 × 1280` | `p_max - 87 × 995.29`（标准） |
| 预初始化偏移 | `1 × 1280` | `1 × 995.29` |
| 离开光耦距离 | `8 × 1280` | `8 × 995.29` |
| 软件限位余量 | `p_max + 30000` | `p_max + 60000` |

### 5.6 软件限位

通过 `Tmc5272_Mx_Virtual_Stop_Enable()` 一次写入 3 个寄存器实现硬件级位置限位：

| 序号 | 寄存器 | 写入值 | 含义 |
| ---- | ------ | ------ | ---- |
| 0 | `SW_MODE` | `0x00003000` | 虚拟停止功能开关 |
| 1 | `VIRTUAL_STOP_L` | `p_min` | 左向虚拟停止位置 |
| 2 | `VIRTUAL_STOP_R` | `p_max + 余量` | 右向虚拟停止位置 |

**SW_MODE 寄存器位定义（`0x00003000`）**：

```text
0x00003000 = 0b 0000 0000 0000 0000 0011 0000 0000 0000
                                        ↑↑↑↑
                                        bit13~bit12

bit13 = 1 → virtual_stop_r_en（使能右向虚拟停止）
bit12 = 1 → virtual_stop_l_en（使能左向虚拟停止）
其余位 = 0（中断、latch 等功能关闭）
```

该值**不能随意修改**：只开 bit12/13 是精确需要的配置。改其他位会导致不期望的硬件行为（如触发中断、latch 等），写 `0x00000000` 则完全禁用限位。

仅在 `My_PT_Init()` 中调用一次（`tmc5272_pt.c:5167`）：

```c
Tmc5272_M1_Virtual_Stop_Enable(pan.p_min,  pan.p_max);
Tmc5272_M0_Virtual_Stop_Enable(tilt.p_min, tilt.p_max);
```

### 5.7 VISCA 位置系数

```c
VISCA_PT_PAN_MOTOR_POSITION_COEFFICIENT  = 0.00177775f / PT_TRANSMISSION_RATIO
VISCA_PT_TILT_MOTOR_POSITION_COEFFICIENT = 0.00177775f / PT_TRANSMISSION_RATIO
```

用于 VISCA 协议中角度值与内部脉冲位置的互转。

### 5.8 限位钳位

- **预置位运动**（`PT_Pan_Preset` / `PT_Tilt_Preset`）：目标位置先做钳位 `p_min ≤ target ≤ p_max`
- **连续运动**（`PT_Move_Right/Left/Up/Down`）：方向目标直接设为 `p_max` 或 `p_min`，由软件限位自动截停

### 6.2 单位转换体系

#### 转换层级

```text
VISCA 速度等级 (1~25)
    ↓ 查表 PT_PAN_V_RPS_LIST[速度等级]
角速度 °/s（云台输出轴角速度）
    ↓ Get_Pan_M_V_Rps(speed) = °/s × 减速比 / 360
输出轴转速 rps（云台输出轴转/秒）
    ↓ × 102400 × 2^24 / f_clk
TMC5272 内部单位 ppt (pulses per tick) ← 写入 VMAX/V1/V2 寄存器
```

#### °/s → 输出轴 rps

```text
代码计算值 = °/s × 减速比 / 360

Pan:  °/s × 4.5 / 360 = °/s × 0.0125
Tilt: °/s × 3.5 / 360 = °/s × 0.00972
```

代码实现（`Get_Pan_M_V_Rps`）：

```c
return (PT_PAN_V_RPS_LIST[v] * VX730_PT_PAN_TRANSMISSION_RATIO / 360.0f);
```

注：乘减速比是为了在后续 `× 102400` 换算微步数时抵消减速比，`102400 × 减速比 / 360 × °/s` 正好得到云台转1°对应的电机微步数。

#### rps → ppt

TMC5272 内部速度单位为 **ppt**（pulses per tick），1 tick = 1/f_clk 秒。

```text
v_ppt = 代码计算值(rps) × 107374.1824  (16MHz)

推导：102400 × 2^24 / 16000000 = 107374.1824
即：102400微步/圈 × 2^24 ticks/s / 16MHz时钟 = 微步/tick
```

当前项目配置：`TMC5272_F_CLK_SET = TMC5272_F_CLK_16M`（16MHz）。

#### 加速度转换

```text
a_ppt = a_rps² / coefficient

16MHz：coefficient = 0.001137
  推导：a_ppt = a_rps × 102400 × 2^24 / f_clk² × (512 × 256)
  简化为：a_ppt = a_rps / 0.001137

27MHz：coefficient = 0.003237
```

#### ppt → °/s 反向查询

`Get_PT_Stop_Dec_Speed_Actual(v_ppt)`：将当前 ppt 速度与预计算的 `drv_ppt_match_speed[]` 表比较，找到对应的速度等级（用于选择停止减速度参数）。

### 6.3 ppt 速度预计算表

`Init_Drv_Ppt_Match_Speed_List()` 在启动时为每个速度等级预计算 ppt 值：

## 7. 8段加减速曲线计算

### 设计原理

TMC5272 的8段斜坡（8-point ramp）本质是**用分段常数加速度逼近平滑的S曲线**，核心目标是限制 jerk（加速度变化率），避免激发机械共振。

**为什么是30-40-30和0.3-0.7？**

| 设计选择 | 原理 |
| -------- | ---- |
| V1=30% VMAX | 低速起步，加速度低，减少启动冲击 |
| V2=70% VMAX | 中速过渡，加速度升高 |
| t1=30%, t2=40%, tmax=30% | 中间段最长（40%），承担最大速度变化量（30%→70%），保持加速度可控 |
| 首段30%时间 + 30%速度 | 缓起步：低加速度、短时间，jerk小 |
| 尾段30%时间 + 30%速度范围 | 缓到位：从70%到100%用与首段相同的加速度，平滑到达 |
| 停止曲线用0.1-0.8 | 停止时大部分时间工作在高速段（80%），低速段（10%）仅用于最终柔和着陆 |

> 这些数值是经验调参的结果，在云台应用中平衡"快"（快速响应）和"稳"（不抖动不共振）。理论上可以调整比例，但需实测验证。

### 7.1 计算入口函数

| 函数 | 位置 | 用途 |
| ------ | ------ | ------ |
| `Get_Motor_Suitable_Ramp_Param()` | tmc5272_pt.c:3051 | **主计算函数**，被 M1_Motion/M0_Motion 调用 |
| `Get_M0_Suitable_Ramp_Param()` | tmc5272_pt.c:2775 | M0(Tilt)专用旧版计算（含运行中变速适配） |
| `Set_Stop_Dec_Params()` | tmc5272_pt.c:813 | 预计算24级停止减速度参数（初始化时调用） |

### 7.2 第一步：时间基准计算（temp）

时间基准 `temp` 决定整个加减速过程的总时长，通过 `acc_dec_ref` 系数和当前速度计算。

#### acc_dec_ref 系数（`Get_Pt_Acc_Dec_Ref()`）

| 工作模式 | 时钟 | acc_dec_ref 值 |
| -------- | ---- | --------------- |
| 正常/预置位 | - | 0.2 |
| 跟踪模式 | 16MHz | 0.002 |
| 跟踪模式 | 27MHz | 0.018 |

#### temp 计算规则

```text
正常/预置位模式：
  temp = acc_dec_ref × (v_rps + 0.5) = 0.2 × (v_rps + 0.5)
  正常状态上限：3.0s
  初始化状态上限（PRE_INIT/INIT）：0.2s

跟踪模式：
  temp = acc_dec_ref × (v_rps + 25) = 0.002 × (v_rps + 25)
  上限：0.2s

附加微调：temp += motion_sync_tunning_t（运动同步校准值，默认0.0）
```

**示例（16MHz，正常模式）**：

| 速度等级 | °/s | v_rps | temp | 上限后 |
| -------- | ----- | ------ | ----- | -------- |
| 1 | 0.2 | 0.0025 | 0.1005 | 0.1005 |
| 12 | 17.5 | 0.219 | 0.1438 | 0.1438 |
| 24 | 100.0 | 1.25 | 0.35 | 0.35 |

### 7.3 第二步：时间分配（30-40-30）

```text
t1   = temp × 0.3   （段0：VSTART→V1 加速时间）
t2   = temp × 0.4   （段1：V1→V2 加速时间）
tmax = temp × 0.3   （段2：V2→VMAX 加速时间）
```

### 7.4 第三步：速度分配（0.3-0.7-1.0）

```text
v1   = vmax × 0.3   （第一阈值速度）
v2   = vmax × 0.7   （第二阈值速度）
vmax = vmax          （目标最大速度）
```

对应到 ppt 单位后写入 TMC5272 寄存器。

### 7.5 第四步：加速度计算

```text
a1   = (v1 - 0)    / t1    = vmax × 0.3 / (temp × 0.3)
a2   = (v2 - v1)   / t2    = vmax × 0.4 / (temp × 0.4)
amax = (vmax - v2)  / tmax  = vmax × 0.3 / (temp × 0.3)
```

注意：a1 和 amax 的公式在数学上等价（都是 `vmax/temp`），但因浮点精度和时间分配的非对称性，实际值略有不同。

### 7.6 第五步：加速距离计算

```text
段0距离：从0加速到v1
  s1   = 0.5 × a1 × t1²

段1距离：从v1加速到v2
  s2   = v1 × t1 + 0.5 × a2 × t2²

段2距离：从v2加速到vmax
  smax = v2 × t2 + 0.5 × amax × tmax²

单侧加速总距离（rps单位）
  smun = s1 + s2 + smax

转换为ppt单位
  S    = smun × 102400
```

S 表示**半程**（仅加速侧）的步数距离。完整加减速距离约为 `S × 2`（减速侧对称）。

### 7.7 第六步：单位转换写入寄存器

使用 [6.2 单位转换体系](#62-单位转换体系) 中的公式：

```text
V1/V2/VMAX = v × 107374.1824  (rps → ppt)
A1/A2/AMAX = a / 0.001137     (rps² → ppt/tick²)
```

### 7.8 第七步：运动方向适配

计算完基础参数后，根据当前运动方向和速度进行动态调整。

#### 同方向运动（`Get_Motor_Suitable_Ramp_Param`，跟踪模式）

```text
判断条件：dir_actual 与 dir_target 同号

当前速度 < VMAX（需要加速）：
  ref = (VMAX - v_actual) / VMAX × 0.1
  v1 = v_actual + (VMAX - v_actual) × 0.2
  v2 = v_actual + (VMAX - v_actual) × 0.6
  a1/d1: a1 × ref / A1，  d1 = A1  （加速弱，减速正常）
  a2/d2: a2 × ref / A2，  d2 = A2
  a_max/d_max: AMAX × ref / AMAX，d_max = AMAX

当前速度 > VMAX（需要减速）：
  ref = (v_actual - VMAX) / VMAX × 0.1
  v1 = v_actual - (v_actual - VMAX) × 0.2
  v2 = v_actual - (v_actual - VMAX) × 0.6
  a/d: 同上

当前速度 = VMAX：仅更新 x_target
```

#### 反方向运动 / 静止启动

```text
使用完整基础参数：
  a1=A1, d1=A1, v1=V1
  a2=A2, d2=A2, v2=V2
  a_max=AMAX, d_max=AMAX
  v_max=VMAX
```

#### M0 旧版适配（`Get_M0_Suitable_Ramp_Param`）

M0 的同方向适配 ref 计算不乘 0.1 系数（更激进）：

```text
加速：ref = (VMAX - v_actual) / VMAX        （× 1.0）
减速：ref = (v_actual - VMAX) / VMAX         （× 1.0）
```

### 7.9 第八步：短距离判断

```text
distance = |target - x_actual|

if (S > distance) → 加速距离 > 剩余距离，电机无法达到目标速度
  ret = 1（短距离标志），低速（v_rps < 0.1）时强制使用基础参数
else → 正常距离
  ret = 0
读取 XACTUAL 失败时 → ret = -1
```

### 7.10 第九步：参数修正（M0_Motion / M1_Motion）

写入寄存器前的最终修正：

```c
// 1. 最小参数保护（防止计算值为0导致电机卡死）

    a1 = d1 = 2;   a2 = d2 = 5;   a_max = d_max = 3;
    v1 = 100;  v2 = 200;  v_max = 300;
}

// 2. 跟踪模式加速度减半
// M0_Tilt:  × 0.5
// M1_Pan:   × 0.4
```

### 7.13 加减速时间计算

#### 基本原理


## 8. 停止控制

### 8.1 停止方式总览

| 方式 | 函数 | 原理 | 适用场景 |
| ---- | ---- | ---- | -------- |
| 急停 | `M0/M1_Emergency_Stop()` | GCONF.bit14/15=1，硬件断开所有输出 | 异常保护 |
| 位置保持 | 分散在各调用处 | XTARGET=XACTUAL，保持当前位置 | 跟踪模式 |
| 减速停止 | `PT_Pan/Tilt_Motor_Stop()` | VMAX=0，执行减速曲线后停止 | 正常停止 |

### 8.2 急停

`tmc5272_pt.c:2685` — `M0/M1_Emergency_Stop()`

没有曲线，直接置 GCONF bit14(M0)/bit15(M1) = 1，TMC5272 硬件立刻断开所有电机输出，电机自由停止。

恢复：`M0/M1_Drv_Enn()` 清除对应 bit。

### 8.3 位置保持停止

不修改加减速参数，仅将目标位置设为当前位置。TMC5272 内部按已有曲线自动减速到当前位置停下。主要用于跟踪模式（`PT_Pan_Motor_Stop` 中 TRACK_MODE + init_finish 时）。

### 8.4 减速停止

`tmc5272_pt.c:4427` — `PT_Pan/Tilt_Motor_Stop()`

调用 `Set_Motor_Suitable_Stop_Param(motor_num, speed_actual)`，根据当前速度等级从预计算表中选择停止参数，设置 VMAX=0，写入新的减速曲线参数和目标位置。

#### 参数倍率模式

`Set_Motor_Suitable_Stop_Param()` 根据工作模式和阶段，对预计算参数施加不同倍率（`tmc5272_pt.c:1299`）：

| 模式 | 参数调整 | 效果 |
| ---- | -------- | ---- |
| **复位阶段**（RESET_MODE + INIT/PRE_INIT） | A1×2000, A2×20000, AMAX×6000, DMAX×6000, D2×20000, D1×2000 | 极大值，接近瞬间刹停 |
| **跟踪模式** | DMAX×0.6+40, D2×0.8+80, D1×0.01+5 | 缩小，缓慢柔和减速 |
| **正常模式** | A1×1.2, A2×1.5, AMAX×1.5, DMAX×1.5, D2×1.5, D1×1.2 | 适度放大，平滑减速 |

#### 停止目标位置

```c
x_target = x_actual ± stop_distance × 0.4;  // 沿运动方向延展40%停止距离
// 钳位到 [p_min+1, p_max-1]
```

### 8.5 预计算停止参数

`Init_Stop_Dec_Params()` 为24个速度等级各预计算一组停止减速参数，存储在 `my_stop_dec[24]` 中。

#### 计算公式（`Set_Stop_Dec_Params`）

与运动曲线类似，但速度分配和 acc_dec_ref 不同：

```text
acc_dec_ref = 0.4（固定值）

temp = 0.4 × (Get_Pan_M_V_Rps(speed) + 1)
上限：2.5s

t1 = temp × 0.3,  t2 = temp × 0.4,  tmax = temp × 0.3

速度分配（停止曲线使用 0.1-0.8 比例，不同于运动曲线的 0.3-0.7）：
  v1 = vmax × 0.1
  v2 = vmax × 0.8

加速度：
  amax = (vmax - v2) / tmax
  a2 = (v2 - v1) / t2
  a1 = v1 / t1

停止距离（全程 = × 2）：
  s1 = 0.5 × a1 × t1²
  s2 = v1 × t1 + 0.5 × a2 × t2²
  smax = v2 × t2 + 0.5 × amax × tmax²
  smun = (s1 + s2 + smax) × 2    ← 注意这里是 × 2
  S = smun × 102400
```

#### 存储结构

```c
Stop_Dec->a1 = A1;      Stop_Dec->d1 = A1;     // 对称加减
Stop_Dec->v1 = V1;
Stop_Dec->a2 = A2;      Stop_Dec->d2 = A2;
Stop_Dec->v2 = V2;
Stop_Dec->a_max = AMAX; Stop_Dec->d_max = AMAX;
Stop_Dec->v_max = VMAX;
Stop_Dec->stop_distance = S;   // 停止距离（ppt）
```

### 8.6 堵转检测

通过 `DRV_STATUS` 寄存器 bit31 读取 StallGuard 状态：

```c
Get_PT_Pan_Motor_Stall_Detected() → M1_DRV_STATUS bit31
```

`SG4_THRS` 寄存器（0x3F/0x74）设置堵转检测阈值，默认 `0x00000120`（288）。

### 9.1 Motor_Drv_Task() — 电机驱动执行层

`tmc5272_pt.c:5313`

**职责**：消费命令层设置的运动目标，计算加减速参数，驱动 TMC5272 执行。

```text
Motor_Drv_Task()
 ├── 首次？(dev_reg_init == FALSE)
 │   ├── Init_Stop_Dec_Params()          // 预计算24级停止减速参数

 │   └── Set_PT_Dev_Reg_Init_Flag(TRUE)
 │
 ├── Pan轴 tar_refresh == TRUE？
 │   ├── is_stop？    → PT_Pan_Motor_Stop()         // 减速停止
```

### 9.2 Tmc5272_Pt_Task() — 云台状态机

`tmc5272_pt.c:5400`

**职责**：根据 PT_MODE × PT_STATE 驱动云台生命周期，监控运动状态，管理状态切换。

```text
Tmc5272_Pt_Task()
 └── dev_reg_init == TRUE 时执行
     └── switch(pt_mode)

     ├── PT_RESET_MODE（上电复位/自检）
     │   ├── 60秒超时保护 → 强制设 NORMAL_MODE + init_finish=TRUE
     │   └── switch(pt_state)
     │       ├── PRE_INIT  → 设初始位置，移向p_min，转INIT
     │       ├── INIT      → 寻光耦零点（4步流程）
     │       ├── PRESET    → 运动到HOME，完成后转READY
     │       ├── READY     → 等待
     │       └── ERROR     → 错误处理
     │
     ├── PT_NORMAL_MODE（正常工作）
     │   └── switch(pt_state)
     │       ├── READY  → 检测双轴到达→清除is_running→通知SOC停止
     │       ├── MOVE   → 检测到达→转READY，通知SOC运动中
     │       ├── PRESET → 检测到达→转READY，通知SOC运动中
     │       └── ERROR
     │
     ├── PT_TRACK_MODE（跟踪模式，AI联动，逻辑同NORMAL）
     │
     ├── PT_TEST_MODE（老化测试）
     │
     └── PT_STANDBY_MODE（待机）
```

**状态检测逻辑**（NORMAL/MOVE 状态为例）：

```text
到达判断条件（双轴都必须满足）：
  Pan: position_reached == TRUE  或  (is_stop && v_actual == 0)
  Tilt: position_reached == TRUE 或  (is_stop && v_actual == 0)

双轴都到达 → Set_PT_Working_State(PT_READY_STATUS)
任一轴未到达 → Set_PT_Is_Running_Flag(TRUE) + Send_Pt_Moving_Status_To_Soc(TRUE)
```

### 9.3 协作关系

```text
命令层 (command.c / ir.c)
  │ 设置 x_target, v_target, tar_refresh=TRUE
  ↓
Motor_Drv_Task()          ← "做什么"：计算参数，写寄存器，驱动执行
  │
  ↓ TMC5272 硬件自动执行运动
  │
Tmc5272_Pt_Task()         ← "什么状态"：监控运动完成，管理状态切换
  │ 读取 position_reached / v_actual
  │ 判断运动是否完成 → 切换 pt_state
  │ 在 RESET 模式中驱动光耦搜索流程
  ↓
状态变更 → 可能触发新的 tar_refresh → 下一轮 Motor_Drv_Task 消费
```

**tar_refresh 生产者-消费者机制**：命令层设置 `x_target`/`v_target` 后置 `tar_refresh=TRUE`，`Motor_Drv_Task()` 消费后清 FALSE。保证运动参数只在需要时才计算和写入寄存器。

## 10. 数据上报

上报模块由 `INFO_REPORT` 结构体管理（`pt_report.c`），使用 TMR10 作为 1ms 定时基准（`timer_t_cnt` 自增）。SOC 通过 VISCA 命令控制上报的开启/关闭和频率。

### 10.1 AI 实时上报 — `P_V_Report_Task()`

- **触发条件**：`p_v_report_enable == 1` 且定时周期到达
- **上报内容**：位置 + 速度（15字节帧）
- **VISCA 命令**：`81 0a 11 78 03 xx ff`（xx=频率，0=关闭）

#### 帧格式

`Periodic_Report_Pt_P_V()` 发送 15 字节：

| 字节 | [0] | [1-4] | [5-8] | [9] | [10] | [11] | [12] | [13] | [14] |
| ---- | --- | ----- | ----- | --- | ---- | ---- | ---- | ---- | ---- |
| 含义 | 0x73 | Pan位置 | Tilt位置 | Pan速度整数 | Pan速度小数 | Tilt速度整数 | Tilt速度小数 | 方向标志 | 0xFF |

#### 位置计算

```c
pan_x  = (PT_PAN_MOTOR_POSITION_MAX - Get_PT_Pan_X_Actual())  × (60000 / range_steps)
tilt_x = (PT_TILT_MOTOR_POSITION_MAX - Get_PT_Tilt_X_Actual()) × (60000 / range_steps)
```

将 ppt 绝对位置映射到 0~60000 的标准化值（4字节BCD）。

#### 速度计算（ppt → °/s）

```c
v_pan  = V_actual_ppt × 8.9 / 11995    // Pan速度，含减速比换算
v_tilt = V_actual_ppt × 11.5 / 11995   // Tilt速度，含减速比换算
```

整数部分和小数部分（×100）分两字节发送。

#### 方向标志（byte[13]）

| bit | 1 | 0 |
| --- | - | - |
| bit4（Pan） | 向右 | 向左 |
| bit0（Tilt） | 向上 | 向下 |

### 10.2 Free-D 实时上报 — `Pos_Report_Task()`

- **触发条件**：`pos_report_freed_enable == 1` 且定时周期到达
- **上报内容**：仅位置（10字节帧）
- **VISCA 命令**：`81 0a 11 78 01 xx ff`（xx=频率，0=关闭）

#### Free-D 帧格式

`Periodic_Report_Pt_Pos()` 发送 10 字节：

| 字节 | [0] | [1-4] | [5-8] | [9] |
| ---- | --- | ----- | ----- | --- |
| 含义 | 0x71 | Pan位置 | Tilt位置 | 0xFF |

位置计算与 AI 上报**方向相反**：

```c
pan_x  = (Get_PT_Pan_X_Actual()  - PT_PAN_MOTOR_POSITION_MIN)  × (60000 / range_steps)
tilt_x = (Get_PT_Tilt_X_Actual() - PT_TILT_MOTOR_POSITION_MIN) × (60000 / range_steps)
```

- **Free-D**：从 p_min 开始计算（当前位置 - p_min）
- **AI**：从 p_max 开始计算（p_max - 当前位置）

### 10.3 上报频率控制

```c
period = 1000 / command[6];       // 频率(Hz) → 周期(ms)
if (period < 100) period = 100;   // 最快10Hz
```

频率范围：1~10 Hz（周期 100ms~1000ms）。

两种上报互斥：开启 AI 上报时会关闭其他上报通道（`pos_report_enable = 0, v_report_enable = 0`）。

## 13. 电机速度极限分析

本章回答一个核心问题：**在当前的电机、驱动器、供电条件下，云台最快能转多快？**

分析从三个层面展开：

1. **芯片极限** — TMC5272 寄存器能设置的最高速度
2. **物理极限** — 供电电压和电机电磁特性决定的理论最高速度
3. **工程极限** — 保证不失步、力矩足够驱动负载的实用最高速度

### 13.1 电机规格

#### 电气参数

| 参数 | 值 | 补充说明 |
|------|------|------|
| 步距角 | 0.9° | 400 步/圈（常见电机为 1.8° / 200 步） |
| 相数 | 2 相 | 双极性驱动，适配 TMC5272 |
| 额定电压 | 3.84 V | 相绕组两端电压，R = V/I = 9.6Ω |
| 额定电流 | 0.4 A/相 | TMC5272 需将 IRUN 设低以匹配 |
| 保持转矩 | 0.72 kg·cm (Min) | ≈ 70.6 mN·m，低速时的最大力矩 |
| 相电阻 R | 9.6 Ω | 额定电压 / 额定电流 |
| 相电感 L | 5.0 mH | 决定高速时电流能否快速建立 |

> **为什么步距角重要？** 0.9° 电机比 1.8° 电机多一倍极对数（100 vs 50）。这意味着同一转速下，电机内部的电气频率更高，线圈中的电流变化更快，电感的阻碍作用更强。**0.9° 电机精度高但高速性能更受限。**

#### 机械参数

| 参数 | 值 |
|------|------|
| 外形 | 36mm 机座号（法兰盘 Φ36.5mm），微型步进电机 |
| 轴伸 | Φ4 mm × 6 mm，带扁位 |
| 出线 | A相：黑、绿；B相：红、黄（对应 TMC5272 A/B 相输出） |

#### 配套皮带轮（电机端）

| 参数 | 值 | 补充说明 |
|------|------|------|
| 齿形 | MXL | 微型梯形齿，适用于轻负载精密传动 |
| 齿数 | 16 齿 | 电机端主动轮 |
| 节距 | 2.032 mm | MXL 标准节距 |
| 节圆直径 | 10.35 mm | 每转一圈皮带前进 π × 10.35 ≈ 32.5mm |
| 材料 | H59 黄铜 | |

皮带传动减速比 = 输出端齿数 / 电机端齿数。若为单级传动：Pan 输出端 16 × 4.5 = 72 齿，Tilt 输出端 16 × 3.5 = 56 齿。实际可能为多级传动组合，需确认机械结构。

### 13.2 当前驱动配置

| 参数 | 值 | 代码来源 |
|------|------|------|
| TMC5272 时钟 | 16 MHz | `TMC5272_F_CLK_SET` |
| 电机供电 VM | 12 V | `PWR_ON12V_IN`（部分硬件版本 13V） |
| 满量程电流范围 | 375 mA（Range=2） | `DRV_CONF = 0x0000028A` |
| 运行电流 IRUN | 31/32 → 363 mA | 高速档速度表 |
| 保持电流 IHOLD | 6/32 → 70 mA | 高速档速度表 |
| 微步分辨率 | 256 细分 | CHOPCONF MRES=0 |
| 脉冲数/圈 | 102,400 | 400 步 × 256 微步 |

> **供电 12V vs 电机额定 3.84V？** TMC5272 是斩波驱动器（Chopper Driver），它用 12V 高电压快速向线圈注入电流，达到目标值后用 PWM 斩波维持。供电电压远高于电机额定电压是正常的——**供电电压越高，电流建立越快，高速性能越好。**
>
> **当前驱动电流 363mA = 额定 400mA 的 90.8%**，留有少量余量防止电机过热。

### 13.3 速度换算关系

单位转换链与公式详见 [6.2 单位转换体系](#62-单位转换体系)。本章补充云台角度速度与电机转速的反向换算：

```text
云台°/s = 电机RPM × 6 / 减速比

Pan:  电机RPM × 6 / 4.5 = 电机RPM × 1.333 °/s
Tilt: 电机RPM × 6 / 3.5 = 电机RPM × 1.714 °/s

1 rps = 60 RPM
```

### 13.4 第一层：TMC5272 芯片极限

TMC5272 的 VMAX 寄存器为 24 位有符号整数（±2²³），最大值 8,388,607 ppt。

| 指标 | 计算 | 结果 |
|------|------|------|
| 最大脉冲频率 | 8,388,607 × 16MHz / 2²⁴ | ≈ 8 MHz（800 万脉冲/秒） |
| 电机极限转速 | 8,000,000 / 102,400 | ≈ 78 rps = **4,688 RPM** |
| Pan 云台极限 | 4,688 RPM × 1.333 | **6,250 °/s** |
| Tilt 云台极限 | 4,688 RPM × 1.714 | **8,035 °/s** |

**结论：TMC5272 芯片不是瓶颈。** 当前 Pan 的 VMAX=134,218（利用率 1.6%），Tilt 的 VMAX=73,074（利用率 0.87%），芯片能力远未用满。

### 13.5 第二层：物理极限——为什么电机不能无限快

#### 13.5.1 三个电压"竞争者"

电机的每一相线圈可以简化为 R-L 串联电路。当 TMC5272 驱动电机旋转时，供电电压 12V 要同时对抗三个"竞争者"：

```text
TMC5272 供电电压 12V
    │
    ├──→ 克服电阻压降：V_R = I × R = 0.363A × 9.6Ω = 3.49V
    │    （电流流过线圈电阻的固有损耗，与转速无关）
    │
    ├──→ 克服反电动势：E_back = Ke × ω
    │    （电机转动时像发电机一样产生反向电压，转速越快越大）
    │
    └──→ 克服电感压降：V_L = ω_e × L × I
         （电流在电感中的变化被阻碍，转速越快电流变化越频繁，阻力越大）

剩余可用电压 = 12V - V_R - E_back - V_L
剩余越多 → 驱动器越能有效控制电流 → 力矩越大
剩余为零 → 驱动器无法控制电流 → 力矩为零 → 失步
```

#### 13.5.2 反电动势常数 Ke

反电动势是电机旋转时自身产生的"抵抗电压"（类似发电机原理）。速度越快，反电动势越大，可以用来驱动电机的"净电压"就越少。

```text
Ke = T_holding / (2 × I_rated) = 0.0706 / 0.8 = 0.0883 V·s/rad

含义：电机每 1 rad/s 角速度，产生 0.0883V 的峰值反电动势
```

#### 13.5.3 电感的"刹车"效应

电感 L = 5mH 会阻碍电流的快速变化。转速越高，驱动器需要越频繁地改变电流方向（400 步电机每圈电流方向切换 400 次），电感就越"抗拒"。

关键参数：**400 步电机有 100 个极对**（1.8° 电机只有 50 个），同一转速下电流切换频率是 1.8° 电机的 **2 倍**，电感的阻碍作用也就 **2 倍**。

```text
电气角频率 ω_e = 2π × (RPM/60) × 100   （100个极对）

电感压降 V_L = ω_e × L × I
  = 2π × (RPM/60) × 100 × 0.005H × 0.363A
  = RPM × 0.019V
```

#### 13.5.4 电压方程

将三个竞争者合并（相量形式，V_R 与 V_L+E_back 正交）：

```text
V_required = √(V_R² + (V_L + E_back)²)

当 V_required ≥ 12V 时 → 驱动器无法维持目标电流 → 失步
```

### 13.6 各转速下的电压分配

下表展示 12V 供电在三个"竞争者"之间的分配：

| 电机转速 | 电阻消耗 V_R | 反电动势 E_back | 电感消耗 V_L | 总需求 V_req | 剩余余量 | 力矩 |
|----------|-------------|-----------------|-------------|-------------|---------|------|
| 100 RPM | 3.49V | 0.93V | 1.90V | 4.11V | 66% | 充沛 |
| 200 RPM | 3.49V | 1.85V | 3.80V | 5.87V | 51% | 充裕 |
| 300 RPM | 3.49V | 2.77V | 5.70V | 9.22V | 23% | 良好 |
| **350 RPM** | **3.49V** | **3.23V** | **6.65V** | **10.52V** | **12%** | **可用** |
| 400 RPM | 3.49V | 3.70V | 7.60V | 11.87V | 1% | 微弱 |
| **~405 RPM** | **3.49V** | **~3.75V** | **~7.70V** | **≈12.00V** | **0%** | **失步** |

> **解读**：300 RPM 时 12V 还剩 23% 余量，电机工作稳定；到 350 RPM 余量仅 12%，力矩开始明显衰减；405 RPM 时 12V 被完全消耗，电机力矩为零，无法维持旋转。

### 13.7 第三层：工程极限——云台实际能跑多快

理论极限 405 RPM 时力矩为零，没有实际意义。工程上以力矩衰减到 **50% 左右**（仍有足够力矩驱动负载且不丢步）为可用上限。

**电机实用最高转速：约 300-350 RPM**

换算到云台输出轴速度：

| 电机转速 | Pan 云台 (4.5:1) | Tilt 云台 (3.5:1) | 力矩保持 | 说明 |
|----------|-----------------|-------------------|---------|------|
| 75 RPM | **100 °/s** | — | ~95% | Pan 当前最高档（速度等级24） |
| 41 RPM | — | **70 °/s** | ~95% | Tilt 当前最高档（速度等级20） |
| 200 RPM | 267 °/s | 343 °/s | ~85% | 安全提速区 |
| **300 RPM** | **400 °/s** | **514 °/s** | **~64%** | 推荐提速上限 |
| **350 RPM** | **467 °/s** | **600 °/s** | **~48%** | 激进提速上限 |
| 405 RPM | 540 °/s | 694 °/s | 0% | 不可用（失步） |

> **当前配置 vs 工程极限**：Pan 100→400 °/s（**4 倍**），Tilt 70→514 °/s（**7 倍**）。速度表还有很大的提升空间。
>
> **电机利用率**：当前最高档 Pan 仅 75 RPM / 300 RPM = **25%**，Tilt 仅 41 RPM / 300 RPM = **14%**，电机大部分能力未被使用。

### 13.8 瓶颈定位

```text
  速度
   ^
   │                                              ┌──────── 工程极限
   │                                          ┌───┘         (300-350 RPM)
   │                                      ┌───┘
   │                                  ┌───┘
   │              ┌───────────────────┘  ← 12V 供电决定的物理极限
   │          ┌───┘                         (405 RPM)
   │      ┌───┘
   │  ┌───┘
   │──┘  ← 当前配置 (75 RPM)
   │
   └──────────────────────────────────────────────→ 电机RPM
   0   100   200   300   400   500   ...  4688

```

| 层级 | 限制因素 | Pan 极限 | Tilt 极限 | 距当前 |
|------|---------|---------|----------|-------|
| 芯片层 | VMAX 寄存器 2²³-1 | 6,250 °/s | 8,035 °/s | 60-80 倍 |
| 物理层 | 12V 供电、反电动势、电感 | ~540 °/s | ~694 °/s | 5-7 倍 |
| **工程层** | **50% 力矩阈值** | **400-467 °/s** | **514-600 °/s** | **4-8 倍** |

**结论：瓶颈是"12V 供电 + 5mH 电感 + 0.9° 高极对数电机的组合"，不是 TMC5272 芯片。**

>目前实测460°/S可以达到,但是力矩太小，云台烤机老化会碰壁。


### 13.9 提速方案

| 方案 | 原理 | 预期效果 | 风险与限制 |
|------|------|---------|-----------|
| 提高供电至 24V | 供电翻倍 → 反电动势占比减半 → 理论极限翻倍 | 电机极限 ~800 RPM，Pan ~1,067 °/s，Tilt ~1,371 °/s | 需确认 TMC5272 耐压（最大 36V，可行）和电机线圈绝缘 |
| 提高供电至 18V | 折中方案 | 电机极限 ~600 RPM，Pan ~800 °/s，Tilt ~1,029 °/s | 需评估硬件改动量 |
| 换用低电感电机 | 减小电感压降 V_L 项 | 高速力矩显著提升 | 需重新选型，可能牺牲低速平滑性 |
| 换用 1.8° 电机 | 电气频率减半 → 电感影响减半 | 同转速下力矩保持率更高 | 位置分辨率减半（51200 步/圈 vs 102400） |

> **实测建议**：提速前必须验证（1）电机在目标转速下持续运行是否过热；（2）是否存在丢步（可用 StallGuard4 检测）；（3）MXL 皮带在高速下的传动可靠性；（4）机械结构（轴承、减速齿轮）的承受能力。建议从速度表最高档逐步增加，每次增加 20% 实测确认。

## 14. 停止抖动分析（140°/s 近限位）

### 14.1 问题描述

Pan 轴速度等级 24 从 100°/s 提升至 140°/s 后，主动停止时出现间歇性抖动。关键现象：

```text
✓ 执行 right 命令，云台到达极限位置 → 不抖动（Virtual Stop 停止）
✗ 执行 right 命令，在接近极限位置时主动触发停止 → 抖动（Active Stop 停止）
```

结论：**存在两套完全不同的停止逻辑**，一套正常、一套在高速近限位时有问题。

### 14.2 路径 A：Virtual Stop（虚拟停止，不抖动）

#### 触发条件

连续运动命令（如 `PT_Move_Right`）将 `x_target` 设为 `p_max`，电机向 `p_max` 方向运动，最终被 TMC5272 硬件虚拟停止功能拦截。

#### 工作原理

Virtual Stop 机制详见 [5.6 软件限位](#56-软件限位)。核心特点：

- **零软件干预**：整个减速过程由 TMC5272 芯片内部斜坡发生器处理，不涉及任何寄存器写入
- **精确减速点**：芯片根据当前速度和已写入的 DMAX/D2/D1 参数，自动计算最佳减速起始位置
- **零过冲**：硬件保证在 VIRTUAL_STOP_R 处速度为 0

相关代码（`tmc5272_pt.c`）：

```c
// 初始化时设置（带余量）— Motor_Init() line 3403
Tmc5272_M1_Virtual_Stop_Enable(m1->p_min, m1->p_max + 30000);

// 复位完成后重新设置（精确边界）— My_PT_Init() line 5168
Tmc5272_M1_Virtual_Stop_Enable(Get_PT_Instance()->pan.p_min, Get_PT_Instance()->pan.p_max);
```

### 14.3 路径 B：Active Stop（主动停止，近限位抖动）

#### 触发条件

用户在运动过程中主动发送停止命令，调用 `PT_Pan_Motor_Stop()`（line 4428）。

#### 调用链

```text
PT_Pan_Motor_Stop()                        // line 4428
 ├── v_actual = Get_PT_Pan_Motor_V_Actual()
 ├── speed_actual = Get_PT_Stop_Dec_Speed_Actual(v_actual)  // ppt→速度等级反查
 └── Set_Motor_Suitable_Stop_Param(1, speed_actual)          // line 1300
      ├── 从预计算表获取停止减速参数
      ├── 施加模式倍率（正常模式 ×1.2~×1.5）
      ├── 计算停止目标位置
      └── 写入 10 个寄存器
```

#### 10 个寄存器写入序列（line 1417-1421）

```text
[0] A1     ← 新减速加速度
[1] V1     ← 新阈值速度
[2] A2     ← 新减速加速度
[3] V2     ← 新阈值速度
[4] AMAX   ← 新加速度
[5] VMAX=0 ← 电机立即开始减速！（但 DMAX/D2/D1 还是旧值，XTARGET 也是旧值）
[6] DMAX   ← 新减速参数（电机已在减速中，中途换参数）
[7] D2     ← 新减速参数
[8] D1     ← 新减速参数
[9] XTARGET← 新目标位置（可能被截断到 p_max-1）
```

### 14.4 根因分析

Active Stop 在高速近限位时抖动，有 **三个叠加原因**：

#### 原因 1：目标位置截断 → 减速距离不足

```c
// line 1396-1414
x_target = x_actual + stop_distance * 0.4f;  // 计算停止目标

if(PT_PAN_MOTOR_POSITION_MAX < x_target)
    x_target = PT_PAN_MOTOR_POSITION_MAX - 1; // 截断
```

以 140°/s 为例，`stop_distance × 0.4` 对应的减速距离可能有数万脉冲。但在接近限位时：

```text
例：x_actual = p_max - 5000（距离限位仅 5000 脉冲 ≈ 3.9°）
计算目标：x_target = (p_max - 5000) + stop_distance × 0.4 → 远超 p_max
截断后：  x_target = p_max - 1
实际可用减速距离：仅 5000 脉冲

而 140°/s 需要的减速距离远超 5000 脉冲 → 减速空间不足
```

对比 Virtual Stop：芯片根据当前速度精确计算减速起始点，保证有足够的减速距离，不存在截断问题。

#### 原因 2：寄存器写入顺序导致参数不一致

写入 VMAX=0 时（第 5 步），电机立即开始减速，但：

- **DMAX/D2/D1 还是旧的运动参数**（新的减速参数在步骤 6-8 才写入）
- **XTARGET 还是旧的运动目标**（新目标在步骤 9 才写入）

电机在减速过程中，减速参数被逐个替换，目标位置也中途变更。高速运行时，这些中间状态的持续时间相对电机的运动周期不可忽略。

对比 Virtual Stop：整个减速过程不涉及任何寄存器写入，参数始终一致。

#### 原因 3：截断后位置过冲 → 修正振荡

当 XTARGET 被截断到 `p_max - 1`，而电机以 140°/s 高速运行：

```text
1. 电机减速过程中可能冲过 p_max - 1
2. TMC5272 位置控制器检测到 XACTUAL > XTARGET
3. 尝试反向修正 → 回到 p_max - 1
4. 修正过程可能再次过冲 → 来回振荡 = 抖动
```

对比 Virtual Stop：芯片硬件保证不会冲过 VIRTUAL_STOP_R，不存在过冲和修正。

### 14.5 两条路径对比总结

| 对比项 | Virtual Stop（路径 A） | Active Stop（路径 B） |
|--------|----------------------|---------------------|
| 执行者 | TMC5272 芯片内部硬件 | ARM 软件写入 10 个寄存器 |
| 减速参数 | 使用当前已有参数，不变 | 重新计算并覆写 |
| 目标位置 | 不变（原来的 x_target） | 重新计算，近限位时被截断 |
| 寄存器写入 | 零 | 10 次顺序写入 |
| 中间状态 | 无 | 有（VMAX 先写，DMAX/XTARGET 后写） |
| 过冲风险 | 无（硬件精确计算减速点） | 有（截断目标 + 高速惯性） |
| 抖动 | 不抖动 | 近限位高速时抖动 |

### 14.6 修复方向

核心思路：**近限位时避免使用"重构减速参数 + 截断目标"的方式，改用更接近 Virtual Stop 的策略。**

#### 方案 1：近限位时保持位置（推荐）

当检测到可用减速距离不足时，直接 `XTARGET = XACTUAL`（类似跟踪模式的处理方式），让 TMC5272 用当前参数自然减速到当前位置停下：

```c
// 在 Set_Motor_Suitable_Stop_Param() 中增加近限位判断
uint32_t remain = (dir > 0) ? (p_max - x_actual) : (x_actual - p_min);
if (remain < stop_distance * 0.4f) {
    // 近限位：保持当前位置，不改减速参数
    Tmc5272_Reg_Write(TMC5272_M1_XTARGET, x_actual);
    return;
}
```

#### 方案 2：调整寄存器写入顺序

先写 DMAX/D2/D1 和 XTARGET，最后写 VMAX=0。避免电机用旧减速参数开始减速：

```c
// 调整写入顺序：先更新减速参数和目标，最后触发减速
write(D1);
write(D2);
write(DMAX);
write(XTARGET);
// ... 其他参数
write(VMAX = 0);  // 最后写，触发减速
```

#### 方案 3：利用 Virtual Stop 机制

主动停止时，不改减速参数，而是将 XTARGET 设为当前位置（或沿方向略微延展），让 TMC5272 用已有的减速参数自然停止。Virtual Stop 仍然作为最后的安全网防止冲过限位。

## 15. 共振区判断与抑制

### 15.1 共振现象原理

步进电机在特定速度区间会发生机械共振，表现为振动加剧、噪声增大、严重时甚至失步。这是由于步进电机的驱动脉冲频率与机械系统的固有频率重合，导致振幅放大。

机械振动系统可简化为质量-弹簧-阻尼模型：

```
固有频率 fn = (1 / 2π) × √(k / m)

k = 机械刚度（转子轴、皮带、负载的弹性）
m = 转动惯量（转子 + 负载）
```

当驱动脉冲频率 ≈ fn 时，发生共振。共振频率通常在 **5-20 rps**（电机轴）范围内。

### 15.2 共振区识别方法

本项目采用**离线标定**方式识别共振区，而非实时传感器反馈。通过实际运行测试，观察各级速度下的振动/噪声表现，标定出共振敏感区间。

代码中的标定结果（`tmc5272_pt.c:230-261`）：

```c
// Pan 速度列表（°/s，非转速）
// 共振区：PT_PAN_V_RPS_LIST[10] ~ PT_PAN_V_RPS_LIST[11]
static float PT_PAN_V_RPS_LIST[PT_PAN_V_RPS_LIST_SIZE] = {
    // ...
    (19+1),    // 索引10 = 20.0  °/s → 共振区下限
    (21+1.2f), // 索引11 = 22.2  °/s → 共振区上限
    (24+1.4f), // 索引12 = 25.4  °/s → 快速通过速度
    // ...
};
```

| 轴 | 共振区下限 | 共振区上限 | 快速通过速度 |
|----|-----------|-----------|-------------|
| Pan | 22.2 °/s | 25.4 °/s | 25.4 °/s |
| Tilt | 22.2 °/s | 25.4 °/s | 25.4 °/s |

> 注意：代码中 `PT_PAN_V_RPS_LIST[]` 存储的是**角速度（°/s）**，而非电机轴转速（rps）。换算关系：Pan 转速 rps = °/s × 4.5 / 360。

### 15.3 共振区判断逻辑

```c
// tmc5272_pt.c:4832-4838
else if((expect_pan_v > PT_PAN_V_RPS_LIST[10]) && (expect_pan_v < PT_PAN_V_RPS_LIST[11]))
{
    // 共振区速度时
    Get_PT_Instance()->pan.motion_sync_tunning_t =  zoom_t*(1- expect_pan_v/PT_PAN_V_RPS_LIST[11])/1000.0f;
    expect_pan_v = PT_PAN_V_RPS_LIST[11];  // 钳位到共振区上限，快速通过
}

// Tilt 轴同理（tmc5272_pt.c:4849-4853）
```

### 15.4 抑制策略

#### 策略 1：快速通过（速度钳位）

当目标速度落在共振区内时，将速度钳位到共振区上限（25.4 °/s），使电机**快速通过**共振敏感区间，而非长时间停留在共振频率附近。

```c
expect_pan_v = PT_PAN_V_RPS_LIST[11];  // 钳位到 25.4 °/s
```

#### 策略 2：时间偏移（motion_sync_tunning_t）

```c
motion_sync_tunning_t = zoom_t * (1 - v / 25.4) / 1000.0f;
```

计算一个时间偏移量，用于调整加减速曲线的时间基准。当前速度越接近共振区上限（25.4），偏移量越小（电机更快通过）；越接近下限（22.2），偏移量越大。

该偏移量在 `Get_Motor_Suitable_Ramp_Param()` 中叠加到 `temp` 时间基准上：

```c
temp += motion_sync_tunning_t;  // tmc5272_pt.c:481
```

#### 策略 3：TPFD 被动快速衰减（寄存器级）

TMC5272 的 `CHOPCONF` 寄存器中包含 TPFD（Turn-off Fast Decay Time）配置位：

```c
// tmc5272_pt.c:942
uint8_t TPFD = 0x0;  // 默认禁用

// CHOPCONF 寄存器位定义（tmc5272_pt.c:874）
// TPFD[23:20] — 被动快速衰减时间，用于抑制电机中速共振
// %0000：禁用
// %0001-%1111：1-15 (NCLK=128×TPFD)
```

TPFD 在斩波器控制中抑制**中速共振**（约 5-20 rps）。当前 TPFD=0 表示未启用此功能。

- 负载惯性匹配不当

### 15.7 恒定抖动（规律性抖点）原因分析

某些速度等级（如 3.0、4.0、16.0 °/s）在运行过程中持续出现规律性抖动，与偶发抖动不同，这种抖动在相同速度下**稳定复现**。可能原因如下：

#### 原因 1：机械传动特定频率共振

皮带轮或减速机构存在固有频率。当输入转速对应的脉冲频率与传动系统的固有频率重合时，会引发共振放大。

- **3.0 °/s**：输出轴约 0.0083 rps，电机端经减速比放大后，可能接近某阶固有频率
- **4.0 °/s**：同样可能落在皮带轮或减速机构的谐振区间
- **16.0 °/s**：高频端，可能触发减速箱齿轮系的特定模态

**排查方向**：更换减速比（改变皮带轮直径）或在传动连接处增加阻尼。

#### 原因 2：电机极对数电气谐振

0.9° 步进电机有 100 个极对（200 个电气步距角/转）。特定转速下，脉冲频率会与电机绕组的感抗特性产生谐振：

```text
f_pulse = v_rps × 200
```

例如 4.0 °/s（输出轴约 0.011 rps），经减速比放大后电机转速更高，对应的脉冲频率可能与绕组 LC 谐振。

**排查方向**：尝试 SpreadCycle 斩波模式（相比 StealthChop2 在中速段电气特性更稳定）。

#### 原因 3：StealthChop2 电流控制模式固有缺陷

当前 TMC5272 使用 StealthChop2（静音模式），该模式通过 PWM 调制控制电流，在特定速度区间（约 2-15 rps 电机端）电流控制平滑度下降：

- 低速时续流时间短，PWM 纹波明显
- 中速时电流零点附近可能出现切换噪声
- 3.0、4.0 °/s 可能落在 StealthChop2 效率较低的区间

**排查方向**：

- 在特定速度等级切换到 SpreadCycle 模式
- 调整 PWMFREQ 或 microstep entries 参数优化纹波

#### 原因 4：扩展加速区间偶发抖动

规律性抖点之外的**偶发抖**（不稳定出现）通常与以下因素相关：

- **加减速切换点的加速度突变**：特别是 0.3-0.7-1.0 速度分配在切换时可能产生瞬时扭矩波动
- **负载惯性突变**：云台机构在特定角度时负载重心变化，触发短暂振动
- **供电电压波动**：大电流加速时母线电压跌落，影响驱动电流稳定性
- **细分跳变**：某些速度区间细分等级切换（如 16 细分→ 8 细分）可能引起步距不均

**排查方向**：检查供电稳压、确认加速度曲线平滑度、分析负载重心变化区间。

## 16 TMC5272 速度阈值 (TPWMTHRS) 到 输出轴角速度 (°/s) 完整推导过程

### 1. 已知参数定义

| 符号 | 含义 | 当前值 |
| :--- | :--- | :--- |
| $f_{CLK}$ | TMC5272 内部时钟频率 | $16,000,000 \text{ Hz}$ |
| $TPWMTHRS$ | 速度阈值寄存器设定值 | $86 \text{ (0x56)}$ |
| $MRES$ | 微步分辨率 (每 fullstep 的 $\mu$step 数) | $256$ |
| $N_{step}$ | 电机单圈 fullstep 数 ($360^\circ / 0.9^\circ$) | $400 \text{ fullsteps/rev}$ |
| $GR$ | 减速比 (电机轴转数 / 输出轴转数) | $4.5$ |

### 2. 逐步推导过程

#### 步骤 1：计算单个微步周期 $T_{\mu step}$
**物理意义：** 驱动器发出一个 1/256 微步所需的时间（单位：秒）。

**计算公式：**
$$ T_{\mu step} = \frac{TPWMTHRS}{f_{CLK}} $$

**代入数值：**
$$ T_{\mu step} = \frac{86}{16,000,000} = 0.000005375 \text{ s} \ (5.375\ \mu s) $$

#### 步骤 2：计算微步频率 $f_{\mu step}$
**物理意义：** 每秒钟驱动器发出的微步脉冲数量。

**计算公式：**
$$ f_{\mu step} = \frac{1}{T_{\mu step}} = \frac{f_{CLK}}{TPWMTHRS} $$

**代入数值：**
$$ f_{\mu step} = \frac{16,000,000}{86} \approx 186,046.51 \text{ }\mu\text{steps/s (Hz)} $$

#### 步骤 3：计算整步频率 $f_{step}$
**物理意义：** 换算为电机每秒钟走过的完整步数。

**计算公式：**
$$ f_{step} = \frac{f_{\mu step}}{MRES} $$

**代入数值：**
$$ f_{step} = \frac{186,046.51}{256} \approx 726.74 \text{ fullsteps/s (Hz)} $$

#### 步骤 4：计算电机轴角速度 $\omega_{motor}$
**物理意义：** 步进电机转子本身每秒钟旋转的角度 (°/s)。
*注：由于 1圈 = 360°，需用整步频率除以单圈步数得到圈数，再乘以 360°。*

**计算公式：**
$$ \omega_{motor} = \left( \frac{f_{step}}{N_{step}} \right) \times 360^\circ $$

**代入数值：**
$$ \omega_{motor} = \left( \frac{726.74}{400} \right) \times 360 = 1.81685 \times 360 \approx \mathbf{654.07\ ^\circ/s} $$

#### 步骤 5：计算输出轴角速度 $\omega_{out}$ (目标量)
**物理意义：** 经过减速箱后，最终机械执行机构每秒钟旋转的角度 (°/s)。

**计算公式：**
$$ \omega_{out} = \frac{\omega_{motor}}{GR} $$

**代入数值：**
$$ \omega_{out} = \frac{654.07}{4.5} \approx \mathbf{145.35\ ^\circ/s} $$

---

#### 3. 终极推导公式 (One-liner)

为了在软件代码中一步到位完成计算，我们将上述步骤合并为一个总代数表达式：

$$ \omega_{out\_deg} = \frac{f_{CLK} \times 360}{TPWMTHRS \times MRES \times N_{step} \times GR} $$

**验证计算：**
$$ \omega_{out\_deg} = \frac{16,000,000 \times 360}{86 \times 256 \times 400 \times 4.5} $$
$$ \omega_{out\_deg} = \frac{5,760,000,000}{39,628,800} \approx \mathbf{145.3488\ ^\circ/s} $$
