# MS35774开发

## 芯片概述

**MS35774 / MS35774A** 是杭州瑞盟科技（Relmon/Ruimeng）生产的一款**高精度、低噪声两相步进电机驱动芯片**，内置功率 MOSFET（全桥结构，双 NDMOS），主要面向工业设备、医疗器械、3D 打印等精密运动控制场景。

典型应用：Creality Ender 3 V3 SE 等 3D 打印机主板。

## 关键参数

| 参数 | 值 |
|------|------|
| 驱动类型 | 两相步进电机 |
| 输出结构 | 全桥，双 NDMOS |
| 供电电压 | 4.7V ~ 36V |
| 逻辑控制电压 | 1.8V ~ 5.25V |
| 峰值输出电流 | 2A |
| 平均工作电流 | 1.4A |

| 外部步进模式 | 2 / 4 / 8 / 16 微步进（MS1/MS2 引脚选择） |
| 控制接口 | STEP/DIR（无 SPI） |
| 封装 | QFN-28-EP(5x5) |
| RoHS | 符合 |

## 功能特性

- **内部 256 级电流细分**：自动将电流波形插值为 256 级正弦/余弦输出，实现超低噪声运行（无需配置，自动生效）
- **STEP/DIR 接口**：标准步进控制接口，通过 MS1/MS2 引脚选择 2/4/8/16 微步进模式
- **内部 STEP 脉冲发生器**：适用于需要精确时间和速度控制（而非位置控制）的应用
- **速度自适应力矩调整**
- **电机静止自动省电模式**
- **内置保护功能**：
  - 过温保护 (OTP)
  - 欠压保护 (UVLO)
  - 过流保护 (OCP)
  - 短地保护

## 细分说明

MS35774 的"细分"涉及两个层面，容易混淆：

### 外部步进模式（用户控制）

由 **MS1 / MS2** 引脚电平决定，即每个 STEP 脉冲对应多少步。MS1/MS2 内置 160kΩ 下拉电阻，**上电默认 MS1=0、MS2=0，即 1/8（八细分）**。

| MS2 | MS1 | 步进方式 | 备注 |
|-----|-----|---------|------|
| 0 | 0 | 1/8（八细分） | **上电默认** |
| 0 | 1 | 1/2（半步） | |
| 1 | 0 | 1/4（四细分） | |
| 1 | 1 | 1/16（十六细分） | |

### 内部 256 细分（芯片自动）

芯片内部将电流波形插值为 256 个等级，生成平滑的正弦/余弦电流驱动电机。这是**芯片内部自动完成的，不需要用户配置**，也是低噪声的来源。

### 两者关系

- 用户发 STEP 脉冲 → 按 MS1/MS2 设定的细分（默认 8 细分）步进
- 芯片内部 → 自动用 256 级电流波形实现平滑驱动
- 内部 256 细分始终生效，与外部步进模式无关

## 控制方式

MS35774 **没有 SPI 接口**（28 引脚中无 SPI 相关引脚），仅支持 STEP/DIR 直接控制。

| 参数 | 配置方式 |
|------|---------|
| 微步细分 | 通过 **MS1 / MS2 引脚** 电平选择 2/4/8/16（见上方真值表） |
| 驱动电流 | 通过 **VREF 引脚** 电压设定（外部电阻分压或 DAC） |
| 使能控制 | **ENN 引脚** 低电平使能，上电默认使能 |
| 保护功能 | 过温/欠压/过流保护上电即生效，无需配置 |
| 内部 256 细分 | 自动生效，不可配置 |

**最小接线（4 核心信号线）**：STEP、DIR、ENN、VREF，加上电机输出和电源即可工作。

## 开发要点

### 典型应用注意事项

1. **散热**：QFN-28-EP 封装底部有裸露散热焊盘，需良好焊接至 PCB 散热铜皮
2. **电流设置**：通过 VREF 引脚电压设定，计算公式见数据手册，最大不超过 2A 峰值
3. **供电**：电机供电 (VM) 4.7~ 36V，逻辑供电 (VIO) 1.8~5.25V，注意去耦电容放置
4. **电荷泵**：CPI-CPO 之间接 22nF 电容，VCP-VM 之间接 100nF 电容，不可省略
