# 地平线 X3 开发心得

## 1. 芯片概述

| 参数 | 规格 |
| ---- | ---- |
| CPU | 四核 ARM Cortex-A53, 1.2 GHz（可超频至 1.5 GHz） |
| BPU | 双核 Bernoulli 2.0 架构, ~5 TOPS (INT8) |
| 内存 | 2GB / 4GB LPDDR4 |
| 存储 | MicroSD (TF) 卡 |
| 视频编码 | H.264 / H.265 硬件编码 |
| 视频解码 | H.264 / H.265 硬件解码 |
| 摄像头接口 | MIPI CSI 2-lane x 2 |
| 显示输出 | HDMI x 1, MIPI-DSI x 1 |
| USB | USB 3.0 x 1, USB 2.0 x 2 |
| 以太网 | 千兆 RJ45 |
| WiFi/蓝牙 | 2.4GHz WiFi + BT 4.1 |
| 40-pin 扩展 | 兼容 Raspberry Pi (GPIO/I2C/SPI/UART/PWM) |

## 2. 开发环境搭建

### 2.1 系统安装

1. 下载 Ubuntu 20.04 镜像（`system_sdcard.img`）
2. 使用 balenaEtcher 或 rufus 将镜像写入 MicroSD 卡
3. 插入 TF 卡，USB-C 供电启动
4. 首次启动自动安装工具包（1-2 分钟），完成后自动重启
5. 默认登录：用户 `sunrise`，密码 `sunrise`

### 2.2 网络配置

默认静态 IP：`192.168.1.10`，配置文件 `/etc/network/interfaces`。

```bash
ssh sunrise@192.168.1.10
```

### 2.3 外设使能

```bash
sudo srpi-config    # 切换 SPI2, I2C0, I2S0, I2S1, UART3
```

### 2.4 AI 工具链（主机端 Docker）

模型转换工具链（hb_mapper）在 x86_64 主机的 Docker 中运行，不在 X3 板上。

```bash
# 拉取工具链镜像
docker pull horizon/x3-dev:latest

# 启动容器
docker run -it --rm \
    -v /path/to/your/model:/workspace/model \
    horizon/x3-dev:latest /bin/bash
```

## 3. BPU / AI 推理

### 3.1 模型转换流程（ONNX -> .bin）

#### 步骤 1：导出 ONNX 模型

```python
import torch
torch.onnx.export(model, dummy_input, "model.onnx", opset_version=11)
```

#### 步骤 2：检查模型兼容性

```bash
hb_mapper checker --model-type onnx --march bernoulli2 --model model.onnx
```

#### 步骤 3：编写 YAML 配置（`convert.yaml`）

```yaml
model_parameters:
  onnx_model: './model.onnx'
  march: "bernoulli2"
  output_model_file_prefix: 'model'
  working_dir: './output'

input_parameters:
  input_type_rt: 'rgb'
  input_layout_rt: 'NCHW'
  input_type_train: 'rgb'
  input_layout_train: 'NCHW'
  norm_type: 'data_scale'
  scale_value: 0.003921568627451

calibration_parameters:
  cal_data_dir: './calibration_data'
  cal_data_type: 'float32'

compiler_parameters:
  compile_mode: 'latency'
  optimize_level: 'O3'
```

#### 步骤 4：量化编译

```bash
hb_mapper makertbin --config convert.yaml
```

#### 步骤 5：板上性能测试

```bash
hrt_model_exec perf --model_file model.bin --core_id=0 \
    --frame_count=200 --thread_num=1
```

### 3.2 Python 推理（板上）

```python
from hobot_dnn import pyeasy_dnn as dnn
import numpy as np
import cv2

# 加载模型
models = dnn.load('model.bin')

# 查看输入属性
print("输入形状:", models[0].inputs[0].properties.shape)

# 准备输入数据
h, w = models[0].inputs[0].properties.shape[1:3]
img = cv2.imread('test.jpg')
img = cv2.resize(img, (w, h))
img = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
img = np.expand_dims(img, 0)

# 推理
outputs = models[0].forward(img)
result = outputs[0].buffer  # numpy ndarray
```

## 4. 摄像头 / Sensor 接入

### 4.1 MIPI 摄像头

X3 有两个 MIPI CSI 2-lane 接口。默认配套 Sensor 为 F37 (GC2053)，也支持 OV5647、IMX219、IMX477。

视频管道结构：

```text
Sensor -> MIPI CSI -> VIN -> ISP -> V4L2 output (/dev/videoX)
```

```bash
# 测试 MIPI 摄像头
cd /app/ai_inference/03_mipi_camera_sample
sudo python3 mipi_camera.py

# 查看摄像头内核日志
dmesg | grep -i "mipi\|csi\|sensor\|vin"

# 查看媒体拓扑
media-ctl -p

# 检测 Sensor I2C 地址
i2cdetect -y <bus_number>
```

Sensor 库路径：`/lib/sensorlib/`，摄像头模块库路径：`/etc/cam/`。

### 4.2 USB 摄像头

```bash
ls /dev/video*
v4l2-ctl -d /dev/video8 --all
ffplay /dev/video8
```

## 6. GPIO / I2C / SPI / UART

### 6.1 GPIO sysfs

```bash
# 导出 GPIO（如板载 LED: GPIO105 = BCM26）
echo 105 > /sys/class/gpio/export

# 设置方向
echo out > /sys/class/gpio/gpio105/direction

# 输出高低电平
echo 1 > /sys/class/gpio/gpio105/value
echo 0 > /sys/class/gpio/gpio105/value

# 读取
cat /sys/class/gpio/gpio105/value

# 释放
echo 105 > /sys/class/gpio/unexport
```

### 6.2 GPIO Python（Hobot.GPIO）

```python
import Hobot.GPIO as GPIO

GPIO.setmode(GPIO.BOARD)    # 或 GPIO.BCM, GPIO.SOC
GPIO.setwarnings(False)

GPIO.setup(channel, GPIO.OUT, initial=GPIO.HIGH)
GPIO.output(channel, GPIO.HIGH)
val = GPIO.input(channel)

# 边沿中断
def callback_fn(channel):
    print("Edge on", channel)

GPIO.add_event_detect(channel, GPIO.RISING, callback=callback_fn, bouncetime=200)
GPIO.cleanup()
```

40-pin 引脚编号对照：

| 编号方式 | 说明 |
| -------- | ---- |
| BOARD | 物理引脚号 1-40 |
| BCM | 类 Broadcom 编号 |
| SOC | X3M 芯片原生 GPIO 号 |

### 6.3 I2C

```bash
sudo i2cdetect -y -r 0
sudo i2cdetect -y -r 1
```

```python
from smbus2 import SMBus

```

### 6.4 SPI

40-pin 座上的 SPI2：

```python
import spidev

spi = spidev.SpiDev()
spi.open(2, 0)               # bus 2, device 0
spi.max_speed_hz = 12000000   # 12 MHz
resp = spi.xfer2([0x55, 0xAA])
spi.close()
```

### 6.5 UART

- `/dev/ttyS0` — 系统调试串口（勿作他用）
- `/dev/ttyS3` — 40-pin 扩展串口（pin 8 TX, pin 10 RX）

```bash
sudo stty -F /dev/ttyS3 speed 115200 cs8 -parenb -cstopb
echo "hello" > /dev/ttyS3
cat /dev/ttyS3
```

### 6.6 PWM

```bash
# PWM0（pin 33）
echo 0 > /sys/class/pwm/pwmchip0/export
echo 20000 > /sys/class/pwm/pwmchip0/pwm0/period      # 20ms 周期
echo 10000 > /sys/class/pwm/pwmchip0/pwm0/duty_cycle   # 50% 占空比
echo 1 > /sys/class/pwm/pwmchip0/pwm0/enable
```

## 7. 系统调试命令

### 7.1 系统状态

```bash
# SoM 综合状态（CPU频率、温度、BPU占用、内存）
sudo hrut_somstat

# CPU 频率
cat /sys/devices/system/cpu/cpu0/cpufreq/scaling_cur_freq

# 设置性能模式
sudo bash -c 'echo performance > /sys/devices/system/cpu/cpufreq/policy0/scaling_governor'

# 超频至 1.5 GHz（需主动散热）
sudo bash -c 'echo 1 > /sys/devices/system/cpu/cpufreq/boost'

# 芯片温度（值 / 1000 = 摄氏度）
cat /sys/class/thermal/thermal_zone0/temp
```

## 8. 系统启动流程

```text
BootROM（片上 ROM）
  → 硬件自检，检测启动介质（SD/eMMC/NAND/UART）
  → 加载 SPL
SPL / boot0
  → DDR 初始化，DRAM 训练
  → 加载 U-Boot
U-Boot
  → 硬件初始化（网络、USB、显示）
  → 加载内核 + DTB
  → 传递 bootargs，跳转内核
Linux Kernel
  → 驱动初始化，挂载 rootfs
User Space
  → systemd 服务启动
```

典型分区布局：

| 分区 | 内容 |
| ---- | ---- |
| spl / boot0 | 二级引导（DDR 初始化） |
| uboot | U-Boot |
| env | U-Boot 环境变量 |
| boot / kernel | 内核 + DTB |
| rootfs | 根文件系统（Ubuntu 20.04） |

## 10. 常见问题

| 问题 | 原因 | 解决 |
| ---- | ---- | ---- |
| 首次上电无 HDMI 输出 | TF 卡镜像问题或首次安装中 | 串口检查；等待首次安装完成；重新刷卡 |
| BPU 推理精度严重下降 | INT8 量化信息丢失 | 增加校准数据（50-200 张图）；换 `kl` 或 `mix` 校准 |
| BPU 占用高但吞吐低 | 单线程瓶颈 | 使用 `thread_num=2` 利用双核 BPU |
| CPU 写 BPU 内存数据不一致 | CPU 写缓存，BPU 读到陈旧数据 | BPU 推理前刷新 cache |
| MIPI 摄像头未检测到 | 排线松动或 I2C 失败 | 检查排线方向（金属面朝下）；`i2cdetect` 验证 |
| 长时间运行不稳定 | 超频过热 | 关闭超频（`echo 0 > .../boost`）；加装散热风扇 |
| 磁盘空间不足 | 日志或缓存堆积 | `sudo apt clean`；清理 `/userdata/log/` 和 `/userdata/cache/` |
| ONNX 模型算子不支持 | BPU 仅支持部分算子 | `hb_mapper checker` 检查；替换为支持算子 |
