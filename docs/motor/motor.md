# 电机概述

## 1. 电机分类

电机（Electric Motor）是将电能转换为机械能的装置，根据供电类型和工作原理可分为：

```
电机
├── 直流电机 (DC Motor)
│   ├── 有刷直流电机 (Brushed DC)
│   └── 无刷直流电机 (BLDC)
├── 交流电机 (AC Motor)
│   ├── 异步电机 (Induction)
│   └── 同步电机 (Synchronous)
└── 步进电机 (Stepper Motor)
    ├── 永磁步进 (PM)
    ├── 变磁阻步进 (VR)
    └── 混合步进 (Hybrid)
```

## 2. 直流电机 (DC Motor)

### 2.1 有刷直流电机 (Brushed DC)

**工作原理**：利用电刷与换向器机械接触，实现电流换向。

```
      ┌─────────┐
  ───┤  电刷   ├──┤
      └────┬────┘
           │
      ┌────▼────┐
      │ 换向器  │
      └────┬────┘
           │
      ┌────▼────┐
      │  线圈   │
      └────┬────┘
           │
      └────┴────┘
           │
      ┌────▼────┐
      │  磁极   │
      └─────────┘
```

**特点**：
- 结构简单，成本低
- 调速性能好，启动力矩大
- 电刷磨损，需维护
- 效率较低，寿命有限

**应用**：玩具、小型工具、电动车起步阶段

### 2.2 无刷直流电机 (BLDC)

**工作原理**：通过电子换向器替代机械电刷，实现无接触换向。

```
       ┌──────────┐
       │  电子   │
       │  换向器  │
       └────┬─────┘
            │
    ┌───────┼───────┐
    │       │       │
┌───▼───┐┌──▼───┐┌──▼───┐
│ 绕组A ││绕组B ││绕组C │
└───┬───┘└───┬───┘└───┬───┘
    │       │       │
    └───────┴───────┘
            │
      ┌─────▼─────┐
      │  永磁转子 │
      └───────────┘
```

**特点**：
- 无电刷，寿命长，效率高
- 转速范围宽，噪音低
- 需要电子控制器（ESC）
- 成本较高

**应用**：无人机、电动汽车、空调压缩机、硬盘主轴

## 3. 步进电机 (Stepper Motor)

### 3.1 结构与原理

步进电机将电脉冲信号转化为精确的角位移，每接收一个脉冲，转子转动一个固定角度（步距角）。

```
       定子               转子
    ┌────────┐        ┌────────┐
    │  A+ A- │        │  永磁   │
    │  B+ B- │   ○───│  磁极   │
    │  C+ C- │        │         │
    └────────┘        └────────┘
```

### 3.2 步进电机类型

| 类型 | 转子结构 | 特点 | 应用 |
|------|---------|------|------|
| 永磁式 (PM) | 永磁磁极 | 步距角较大，成本低 | 打印机、FAX |
| 变磁阻式 (VR) | 软铁齿轮 | 响应快，精度高 | 数控机床 |
| 混合式 (Hybrid) | 永磁+软铁 | 精度高，扭矩大 | 3D打印、CNC |

### 3.3 运行模式

**1. 单拍模式（Full Step）**
```
励磁顺序：A → B → C → D → A
```

**2. 双拍模式（Double Step）**
```
励磁顺序：AB → BC → CD → DA → AB
```

**3. 半拍模式（Half Step）**
```
励磁顺序：A → AB → B → BC → C → CD → D → DA → A
```

### 3.4 关键参数

| 参数 | 说明 | 典型值 |
|------|------|--------|
| 步距角 | 每步转动的角度 | 1.8°、0.9°、0.72° |
| 相数 | 绕组数量 | 2相、4相、5相 |
| 保持扭矩 | 停止时的锁定力矩 | 0.1~10 N·m |
| 额定电流 | 每相绕组额定电流 | 0.5~5A |
| 相电阻 | 每相绕组电阻 | 2~20Ω |

### 3.5 驱动方式

**恒压驱动**：简单但温升高，低速力矩小

**恒流驱动**：恒流斩波(Chopper)，温升低，高速性能好

**细分驱动**：微步控制，提高平顺性和精度

### 3.6 应用

- 3D打印机 (XY轴)
- CNC机床 (定位系统)
- 云台/PTZ摄像头
- 自动化设备

## 4. 有刷 vs 无刷 vs 步进

| 特性 | 有刷直流 | 无刷直流 | 步进电机 |
|------|---------|---------|---------|
| 控制方式 | 电压调速 | 电子换向 | 脉冲计数 |
| 位置控制 | 开环困难 | 需反馈 | 开环可精确控制 |
| 效率 | 70-85% | 85-95% | 取决于驱动 |
| 维护 | 需换电刷 | 无需维护 | 无需维护 |
| 成本 | 低 | 中高 | 中 |
| 噪音 | 较大 | 小 | 中等 |
| 适用场景 | 简单调速 | 高性能连续运行 | 精确定位 |

## 5. 选型要点

1. **扭矩需求**：峰值扭矩 vs 持续扭矩
2. **转速范围**：最高转速 vs 低速稳定性
3. **控制方式**：开环/闭环，模拟/数字
4. **精度要求**：步距角、分辨率
5. **环境因素**：温度、振动、防护等级
6. **供电条件**：电压、电流限制
7. **尺寸限制**：安装尺寸、轴径
