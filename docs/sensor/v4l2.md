# V4L2 (Video for Linux 2) 基础知识

V4L2 是 Linux 内核中用于视频采集/输出的统一 API 框架，支持 MIPI CSI 传感器、USB 摄像头、硬件编解码器等设备。所有视频驱动开发均基于 V4L2。

## 1. 架构概览

```text
┌─────────────────────────────────────────────────┐
│                  用户空间                        │
│   GStreamer / libcamera / 自定义应用             │
├─────────────────────────────────────────────────┤
│         /dev/videoX  /dev/v4l-subdevX            │
│         /dev/mediaX                              │
├─────────────────────────────────────────────────┤
│               V4L2 核心                          │
│   video_device │ ioctl 分发 │ ctrl_handler      │
├─────────────────────────────────────────────────┤
│           VB2 (videobuf2) 缓冲管理               │
│   vb2_queue   │ DMA allocator (contig/sg)       │
├─────────────────────────────────────────────────┤
│           Media Controller                       │
│   entities    │ pads       │ links              │
├─────────────────────────────────────────────────┤
│              平台驱动层                           │
│   Sensor驱动(I2C) │ CSI驱动 │ ISP驱动           │
├─────────────────────────────────────────────────┤
│              硬件                                │
│   IMX219 Sensor   │ MIPI CSI   │ RK ISP        │
└─────────────────────────────────────────────────┘
```

核心数据结构：

| 结构体 | 用途 |
| ------ | ------ |
| `struct v4l2_device` | 顶层 V4L2 设备实例 |
| `struct video_device` | 对应 `/dev/videoX` 设备节点 |
| `struct v4l2_ioctl_ops` | ioctl 处理函数指针表 |
| `struct vb2_queue` | VB2 缓冲队列 |
| `struct v4l2_subdev` | 子设备（sensor、ISP、CSI 等） |

## 2. 设备节点与能力

### 2.1 设备节点

| 节点 | 用途 |
| ------ | ------ |
| `/dev/videoX` | 视频采集/输出设备 |
| `/dev/v4l-subdevX` | V4L2 子设备（sensor、ISP 等） |
| `/dev/mediaX` | Media Controller 设备 |

### 2.2 能力标志

`VIDIOC_QUERYCAP` 返回的 `capabilities` 字段：

| 标志 | 说明 |
| ------ | ------ |
| `V4L2_CAP_VIDEO_CAPTURE` | 视频采集（单平面） |
| `V4L2_CAP_VIDEO_OUTPUT` | 视频输出 |
| `V4L2_CAP_VIDEO_CAPTURE_MPLANE` | 视频采集（多平面） |
| `V4L2_CAP_VIDEO_M2M` | M2M 编解码 |
| `V4L2_CAP_STREAMING` | 支持流式 I/O（QBUF/DQBUF） |
| `V4L2_CAP_IO_MC` | I/O 由 Media Controller 管理 |

## 3. 关键 ioctl

### 3.1 速查表

| ioctl | 关联结构体 | 说明 |
| ------ | ------ | ------ |
| `VIDIOC_QUERYCAP` | `v4l2_capability` | 查询设备能力 |
| `VIDIOC_ENUM_FMT` | `v4l2_fmtdesc` | 枚举支持的像素格式 |
| `VIDIOC_G_FMT` / `S_FMT` / `TRY_FMT` | `v4l2_format` | 获取/设置/尝试格式 |
| `VIDIOC_REQBUFS` | `v4l2_requestbuffers` | 请求缓冲区 |
| `VIDIOC_QBUF` / `DQBUF` | `v4l2_buffer` | 入队/出队缓冲区 |
| `VIDIOC_STREAMON` / `STREAMOFF` | `v4l2_buf_type` | 启动/停止流 |
| `VIDIOC_G_PARM` / `S_PARM` | `v4l2_streamparm` | 获取/设置帧率 |
| `VIDIOC_G_CTRL` / `S_CTRL` | `v4l2_control` | 获取/设置控制项 |
| `VIDIOC_QUERYCTRL` | `v4l2_queryctrl` | 查询控制项范围 |

### 3.2 子设备 ioctl

子设备通过 `/dev/v4l-subdevX` 操作，以 **pad** 为单位配置：

| ioctl | 关联结构体 | 说明 |
| ------ | ------ | ------ |
| `VIDIOC_SUBDEV_G_FMT` / `S_FMT` | `v4l2_subdev_format` | 获取/设置 pad 格式 |
| `VIDIOC_SUBDEV_G_FRAME_INTERVAL` / `S_FRAME_INTERVAL` | `v4l2_subdev_frame_interval` | 获取/设置帧率 |
| `VIDIOC_SUBDEV_ENUM_MBUS_CODE` | `v4l2_subdev_mbus_code_enum` | 枚举媒体总线格式码 |
| `VIDIOC_SUBDEV_ENUM_FRAME_SIZE` | `v4l2_subdev_frame_size_enum` | 枚举帧尺寸 |
| `VIDIOC_SUBDEV_S_ROUTING` | `v4l2_subdev_routing` | 配置路由（多流） |

## 4. 缓冲管理 (VB2)

### 4.1 内存类型

| 类型 | 常量 | 说明 | 适用场景 |
| ------ | ------ | ------ | ------ |
| **MMAP** | `V4L2_MEMORY_MMAP` | 内核分配，用户空间 mmap 映射 | 最常用，嵌入式默认 |
| **USERPTR** | `V4L2_MEMORY_USERPTR` | 用户空间分配，传指针给内核 | 用户控制内存位置 |
| **DMABUF** | `V4L2_MEMORY_DMABUF` | DMA-BUF fd 共享 | 零拷贝跨设备（ISP↔编码器） |

### 4.2 缓冲区状态机

```text
                     VIDIOC_QBUF
  ┌──────────┐ ─────────────────► ┌──────────┐
  │ DEQUEUED │                    │  QUEUED  │
  │(用户空间) │ ◄────────────────  │(驱动队列) │
  └──────────┘                    └────┬─────┘
       ▲                               │ DMA 开始
       │ VIDIOC_DQBUF                  │
       │                               ▼
       └────────────────────── ┌──────────┐
              (或 ERROR)       │   DONE   │
                               └──────────┘
```

### 4.3 MMAP 采集完整流程

```text
 1. open("/dev/video0")
 2. VIDIOC_S_FMT              ← 设置分辨率、像素格式
 3. VIDIOC_REQBUFS            ← 请求缓冲区（count=4, MMAP）
 4. VIDIOC_QUERYBUF + mmap()  ← 查询并映射每个缓冲区
 5. VIDIOC_QBUF × N           ← 所有缓冲区入队
 6. VIDIOC_STREAMON           ← 启动采集
 7. ┌─ 循环 ─────────────────────────────────────┐
    │  VIDIOC_DQBUF      ← 取回已填充的帧        │
    │  处理帧数据                                 │
    │  VIDIOC_QBUF       ← 重新入队               │
    └─────────────────────────────────────────────┘
 8. VIDIOC_STREAMOFF          ← 停止采集
 9. munmap() + close()
```

### 4.4 DMABUF 零拷贝共享

```c
// 从 DRM/GPU 导出 DMA-BUF fd
int dmabuf_fd = drmPrimeHandleToFD(handle);

// 使用 DMABUF 入队
struct v4l2_buffer buf = {
    .type   = V4L2_BUF_TYPE_VIDEO_CAPTURE,
    .memory = V4L2_MEMORY_DMABUF,
    .m.fd   = dmabuf_fd,
};
ioctl(fd, VIDIOC_QBUF, &buf);
```

## 5. 子设备与 Media Controller

### 5.1 管线拓扑

子设备框架将硬件管线建模为 entity → pad → link：

```text
 [Sensor IMX219]     [CSI-2 Receiver]     [ISP]        [Video Capture]
  /dev/v4l-subdev1    /dev/v4l-subdev0    /dev/v4l-subdev2  /dev/video0
  [source pad 0] ──► [sink pad 0]
                      [source pad 1] ────► [sink pad 0]
                                           [source pad 1] ──► [sink pad 0]
```

### 5.2 子设备配置示例

```c
int sd_fd = open("/dev/v4l-subdev1", O_RDWR);

// 设置传感器输出格式（source pad 0）
struct v4l2_subdev_format fmt = {
    .which = V4L2_SUBDEV_FORMAT_ACTIVE,
    .pad   = 0,
    .format = {
        .width  = 1920,
        .height = 1080,
        .code   = MEDIA_BUS_FMT_SRGGB10_1X10,
        .field  = V4L2_FIELD_NONE,
    },
};
ioctl(sd_fd, VIDIOC_SUBDEV_S_FMT, &fmt);

// 设置帧率 30fps
struct v4l2_subdev_frame_interval fi = {
    .pad = 0,
    .interval = { .numerator = 1, .denominator = 30 },
};
ioctl(sd_fd, VIDIOC_SUBDEV_S_FRAME_INTERVAL, &fi);
```

### 5.3 媒体总线格式码

子设备 pad 使用 `MEDIA_BUS_FMT_*` 格式码（非 V4L2 pixel format fourcc）：

| 格式码 | 说明 |
| ------ | ------ |
| `MEDIA_BUS_FMT_SRGGB10_1X10` | Bayer RGGB 10-bit |
| `MEDIA_BUS_FMT_SGRBG10_1X10` | Bayer GRBG 10-bit |
| `MEDIA_BUS_FMT_SBGGR10_1X10` | Bayer BGGR 10-bit |
| `MEDIA_BUS_FMT_SRGGB12_1X12` | Bayer RGGB 12-bit |
| `MEDIA_BUS_FMT_UYVY8_1X16` | UYVY 4:2:2 |
| `MEDIA_BUS_FMT_YUYV8_1X16` | YUYV 4:2:2 |

## 6. 像素格式

### 6.1 YUV 格式

| FourCC | 说明 | 每像素字节 |
| ------ | ------ | ------ |
| `V4L2_PIX_FMT_YUYV` | YUV 4:2:2 打包，Y-U-Y-V 交错 | 2 |
| `V4L2_PIX_FMT_UYVY` | YUV 4:2:2 打包，U-Y-V-Y 交错 | 2 |
| `V4L2_PIX_FMT_NV12` | YUV 4:2:0 半平面，Y + UV 交错 | 1.5 |
| `V4L2_PIX_FMT_NV21` | YUV 4:2:0 半平面，Y + VU 交错 | 1.5 |
| `V4L2_PIX_FMT_NV16` | YUV 4:2:2 半平面 | 2 |
| `V4L2_PIX_FMT_YUV420` | YUV 4:2:0 三平面 (I420) | 1.5 |

NV12 内存布局（嵌入式最常用）：

```text
YYYYYYYYYYYYYYYY  ← Y 平面 (W×H 字节)
YYYYYYYYYYYYYYYY
...
UVUVUVUVUVUVUVUV  ← UV 交错平面 (W×H/2 字节)
UVUVUVUVUVUVUVUV
```

### 6.2 Bayer RAW 格式（Sensor 原始输出）

| FourCC | 说明 | 存储 |
| ------ | ------ | ------ |
| `V4L2_PIX_FMT_SRGGB8` | Bayer RGGB 8-bit | 8 bit |
| `V4L2_PIX_FMT_SRGGB10` | Bayer RGGB 10-bit | 16 bit（低 10 位有效） |
| `V4L2_PIX_FMT_SGRBG10` | Bayer GRBG 10-bit | 16 bit |
| `V4L2_PIX_FMT_SBGGR10` | Bayer BGGR 10-bit | 16 bit |
| `V4L2_PIX_FMT_SRGGB12` | Bayer RGGB 12-bit | 16 bit（低 12 位有效） |

Bayer 排列模式：

```text
RGGB:           GRBG:           BGGR:           GBRG:
R G R G ...     G R G R ...     B G B G ...     G B G B ...
G B G B ...     B G B G ...     G R G R ...     R G R G ...
```

### 6.3 压缩格式

| FourCC | 说明 |
| ------ | ------ |
| `V4L2_PIX_FMT_JPEG` | JPEG 压缩图像 |
| `V4L2_PIX_FMT_MJPEG` | Motion-JPEG |
| `V4L2_PIX_FMT_H264` | H.264 NAL 单元流 |
| `V4L2_PIX_FMT_HEVC` | H.265/HEVC 码流 |

## 7. 常用命令行工具

### 7.1 v4l2-ctl（格式/控制调试）

```bash
# 列出所有 V4L2 设备
v4l2-ctl --list-devices

# 查询设备能力
v4l2-ctl -d /dev/video0 --info

# 列出支持的格式
v4l2-ctl -d /dev/video0 --list-formats-ext

# 列出控制项
v4l2-ctl -d /dev/video0 --list-ctrls

# 设置控制项
v4l2-ctl -d /dev/video0 --set-ctrl=brightness=128
v4l2-ctl -d /dev/video0 --set-ctrl=exposure_absolute=1000

# 设置格式并采集单帧
v4l2-ctl -d /dev/video0 \
    --set-fmt-video=width=1920,height=1080,pixelformat=NV12 \
    --stream-mmap --stream-to=frame.yuv --stream-count=1

# 操作子设备
v4l2-ctl -d /dev/v4l-subdev1 --list-ctrls
v4l2-ctl -d /dev/v4l-subdev1 --get-subdev-fmt
```

### 7.2 media-ctl（管线拓扑配置）

```bash
# 打印完整媒体拓扑
media-ctl -d /dev/media0 -p

# 设置子设备 pad 格式
media-ctl -d /dev/media0 \
    --set-v4l2 "'imx219 0-0010':0[fmt:SRGGB10_1X10/1920x1080]"

# 启用/禁用 link（1=ENABLED, 0=DISABLED）
media-ctl -d /dev/media0 \
    --link="'imx219 0-0010':0->'rockchip-mipi-csi2':0[1]"

# 重置拓扑
media-ctl -d /dev/media0 --reset

# 导出 dot 图形
media-ctl -d /dev/media0 --print-dot > topology.dot
dot -Tpng topology.dot > topology.png
```

### 7.3 yavta（快速采集测试）

```bash
# 捕获 10 帧保存到文件
yavta -c10 -n4 -f NV12 -s 1920x1080 -F /dev/video0

# -c N : 捕获 N 帧
# -n N : 请求 N 个缓冲区
# -f FMT : 像素格式
# -s WxH : 分辨率
# -F : 保存到文件
```

### 7.4 工具对比

| 功能 | v4l2-ctl | media-ctl | yavta |
| ------ | ------ | ------ | ------ |
| 操作设备 | `/dev/videoX` | `/dev/mediaX` | `/dev/videoX` |
| 格式/控制查询 | 完整支持 | pad 级别 | 命令行参数 |
| Link 管理 | 不支持 | 核心功能 | 不支持 |
| 帧采集 | 支持 | 不支持 | 核心功能 |
| 所属包 | v4l-utils | v4l-utils | 独立项目 |
