# MIPI C-PHY 主从同步测试结论梳理

## 1. 动态调节问题

### D-PHY 设备表现（原厂验证）

初始序列 60fps，从模式下：

| 帧率范围 | 表现 |
| --- | --- |
| 24fps ~ 49fps | 同步正常 |
| 49fps | 帧率减半 |
| < 24fps | 帧率乘2 |

### C-PHY 设备表现（我方验证）

**初始序列 60fps，从模式下：**

| 帧率范围 | 表现 |
| --- | --- |
| 60fps ~ 31fps | 同步正常 |
| ≤ 30fps | 帧率乘2 |

**初始序列 30fps，从模式下：**

| 帧率范围 | 表现 |
| --- | --- |
| 30fps ~ 24fps | 动态调节正常 |

### 结论

- 动态调节功能可以实现。
- 特定帧率下的倍频/分频现象，因不涉及实际应用场景，可暂时搁置。大帧率切换通常采用切换初始化序列的方式。
- D-PHY 的测试结果不作为我方关注重点。

## 2. 相位对齐问题

### 核心现象

- MIPI 信号从接收到同步信号到出帧存在一个时间差 **Δt**。
- **Δt 的稳定性**是影响相位同步的关键。

### 不同模式下的表现

**VTS_AUTO 模式：**

- Δt 会随帧率变化而波动。

**RESET（手动）模式：**

- Δt 固定。
- 从机可跟随主机帧率，但同步容差范围极小，仅为 **±0.7fps**。超出此范围同步将失效。
- FAE 解释为该模式对主从机帧率一致性要求极高。

## 3. 下一步计划

1. 将我方 C-PHY 序列及 Slave 配置发送给原厂，由其在工板上进行验证，以确认问题一致性。
2. 原厂需要给出auto模式下这个相位对齐问题的详细分析，包括Δt的范围、变化趋势、Δt的位置调整计算公式等。
3. 根据 OV 要求，将我方 SOC 模拟的 Vsync 信号高电平持续时间调整为 60us，以与 Sensor 发出的信号保持一致。
4. 在问题1和问题2确认后，再深入评估相位对齐问题，决策采用 AUTO 还是 RESET 模式。
